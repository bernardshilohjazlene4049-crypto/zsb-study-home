CSS 引入、颜色与链接伪类

同一个页面可以同时使用外部样式表、内部 style 和行内 style；链接有未访问、已访问、悬停、按下四种状态。

外部样式表

将样式写在 `.css` 文件中，再由 HTML 的 `link` 引入，便于多个页面共享。

<link rel="stylesheet" href="css/c1.css">

内部与行内样式

内部样式写在 `<style>`；行内样式写在元素 `style` 属性中。样式的最终结果仍受来源、选择器优先和书写顺序影响。

颜色值

`red`、`blue` 是颜色关键字，`#fff` 是十六进制，`rgb(0,0,255)` 表示蓝。多个属性之间用分号分隔。

链接四状态

  • `:link` 未访问
  • `:visited` 已访问
  • `:hover` 鼠标悬停
  • `:active` 按下时
链接状态试验悬停或按下这个链接

课堂示意：:link、:hover、:active 可直接观察；:visited 受浏览器历史与隐私规则影响，不适合在页面里伪造。

a:link { color: red; }
a:visited { color: green; }
a:hover { color: yellow; font: 30px "楷体"; }
a:active { color: blue; }
自测：给链接设置 30px 楷体，为什么放在 `a:hover` 中只会在悬停时生效？

`a:hover` 只在指针位于链接上时匹配，字体属性自然也只在悬停状态应用。若希望链接默认就是这个字体，应写到 `a` 或 `a:link` 的普通规则。

可视化讲解

自测：外部样式表、内部样式和行内样式，分别适合什么场景？

外部样式表便于多个页面共享和维护；内部样式适合单个页面的集中规则；行内样式只影响一个元素，优先级直观但不利于批量维护。

文本溢出、阴影、缩进与空白

这组属性都作用在文本呈现上，但解决的是不同问题：截断、装饰、段落开头和空格换行规则。

单行溢出

这是一段故意写得足够长的文字，用来展示 text-overflow: ellipsis 的效果。

overflow:hidden; white-space:nowrap; text-overflow:ellipsis;
text-shadow

文字阴影

3px 3px 0 #d8d2ff, 7px 7px 10px #bbb;

text-overflow

`clip` 直接裁掉；`ellipsis` 在末尾显示省略号。单行省略通常同时需要 `overflow:hidden` 和 `white-space:nowrap`。

text-shadow

格式：水平偏移 垂直偏移 模糊半径 颜色。前两个偏移可为负，模糊半径不可为负；可写多个阴影，用逗号分隔。

text-indent

设置首行缩进。`2em` 相当于两个当前字体字号；百分比相对包含块宽度。常用于块级元素，行内元素通常不生效。

white-space

  • `normal`：连续空白折叠，自动换行
  • `pre`：保留空白，按原样换行
  • `nowrap`：折叠空白，不自动换行
  • `pre-wrap`：保留空白并自动换行
  • `pre-line`：折叠部分空白但保留换行
自测：`text-overflow: ellipsis` 单独写为什么经常看不到省略号？

文本必须先真正溢出并被裁剪。常见单行答案还要设置 `overflow:hidden` 与 `white-space:nowrap`。多行省略通常需要浏览器支持的额外布局方案。

课堂自测，依据第 5–6、9–10 张截图整理。

自测：`white-space: nowrap` 与 `pre-wrap` 的关键区别是什么？

`nowrap` 折叠连续空白并禁止自动换行；`pre-wrap` 保留空白和换行，同时允许文本在需要时自动换行。

`:root` 与 `:not` 选择器

`:root` 指向文档根元素，`:not(...)` 匹配参数条件之外的元素。

`:root`

匹配文档的根元素，HTML 中就是 `<html>`。常用来声明全局 CSS 自定义属性，让变量在整个文档中可继承。

:root {
  --brand: #5b4bde;
  --muted: #667085;
}

`:not()`

否定伪类，排除括号中的选择器。例如 `:not(p)` 选择不是段落的元素。它会影响“哪些元素获得样式”，并不会删除被排除元素。

p:not(.lead) { color: #444; }
p:not(.is-excluded)

普通段落：符合选择器，显示绿色强调。

带 .is-excluded：被排除，不显示绿色强调。

易错：`:not(p)` 中括号里写的是要排除的条件；`:root` 不是 `.root` 类选择器，前面的冒号不能省略。
回到网页设计主课CSS 选择器完整课 →伪类与伪元素 →
自测：`:not(.tip)` 会不会选择 class 包含 `tip` 的元素？

不会。它匹配没有 `.tip` 类的元素。若要给 `.tip` 设置样式，应直接使用 `.tip`。

表单、表格与 form 关联属性

表单负责收集数据，表格负责表格数据展示。不要在表格结构允许的位置随意塞表单，并注意 HTML5 的 form 关联方式。

正确嵌套

可以把 table 放进 form，也可以在每个单元格 `td` 内放独立表单。直接把 form 塞在不允许的子元素位置会形成无效结构。

HTML5 `form` 关联

输入控件即使位于 `<form>` 外，也可通过 `form="表单id"` 声明所属表单。课堂第 12 张写了“一个控件可从属多个表单”，但现行 HTML 标准的 `form` 属性是一个 ID 引用；本站示例按单个 id 整理，考场若按指定教材作答请留意这个差异。

<form id="search">…</form>
<input type="text" form="search">
课件原文课堂第 12 张写有一个控件可从属多个表单。
现行标准input 的 form 属性保存一个表单 ID 引用。
作答提示先按题目指定教材作答，同时保留标准差异，不把两者混写成同一规则。
form id="search"定义表单归属
↔
form="search"表外控件声明所属表单

依据现行 HTML 标准，form 属性是一个 ID 引用；课件关于“从属多个表单”的课堂表述已单独标明差异。

回到网页设计主课HTML 表单基础 →HTML5 表单元素 →
<form action="search.php" method="get">
  <table><tr><td><input type="text" name="q"></td></tr></table>
</form>
自测：一个 input 放在 form 后面，还能提交到这个表单吗？

可以。为 form 设置 id，再在 input 上写 `form="对应id"`，即可建立关联。没有关联属性时，表外的普通控件不会自动属于就近表单。

datalist 与范围滑块

用原生 HTML 给文本输入提供建议值和数值范围，减少手工校验。

`datalist`

给 `<datalist>` 设置 id，再用输入框的 `list` 属性关联。用户仍可输入列表外的值，这点与只能从固定选项中选择的 `select` 不同。

<input list="schools">
<datalist id="schools">
  <option value="辽宁大学">
</datalist>

`input[type=range]`

用 `min`、`max`、`step`、`value` 控制范围、步长和初始值。未指定时常见默认范围是 0–100，步长为 1。

<input type="range" min="0" max="100" step="5" value="50">
范围滑块
50

也可以直接使用键盘方向键改变数值。

datalist 输入建议

datalist 提供建议，不限制用户输入列表外的值。

自测：`list="schools"` 中的 schools 写在哪里？

写在 `<datalist>` 的 `id` 上，输入框的 `list` 保存的是 datalist 的 id，而不是“值列表”的内容。
