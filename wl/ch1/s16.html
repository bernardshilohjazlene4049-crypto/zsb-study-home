1.6 IP 地址填空：长度、组成与特殊地址

知识点讲解视频（1）
  • 1.6 IP 地址填空：长度、组成与特殊地址 2:18

第17–20题：IPv4/IPv6 地址长度、地址组成、主机号全1/全0、127.0.0.1、128.11.3.31

【印刷】

17.IP地址长度在IPv4中为______比特，而在IPv6中则为______比特。

18.IP地址分______和______两部分。

19.IP地址的主机部分如果全为1，则表示__________地址，IP地址的主机部分若全为0，则表示__________地址，127.0.0.1被称作__________地址。

20.常用的IP地址有A、B、C三类，128.11.3.31是一个__________类IP地址，

其网络标识（netid）为__________，主机标识（hostid）为__________。

【老师手写】

17：32　128
18：网络号　主机号【第二空字迹潦草，按“主机号”读】
19：（直接）广播　（“直接”二字绿圈）；网络；访问/回送【“访问”二字潦草】
20：B；128.11；3.31；“netid”旁：网络号；“常用的IP地址有A、B、C三类”红线下划线

整理

17：IPv4 地址 32 比特，IPv6 地址 128 比特。

18：IP 地址分网络号和主机号两部分。

19：主机号全 1 → 直接广播地址；主机号全 0 → 网络地址；127.0.0.1 → 访问/回送地址（老师写作“访问/回送”）。

20：128.11.3.31 的第 1 个数 128 在 128~191 → B 类（B 类是“2:2”，见 1-1-1）；网络标识 netid = 128.11（前 2 字节），主机标识 hostid = 3.31（后 2 字节）。

讲解

直观意思 * IP 地址就是互联网上每台设备的“通信门牌号”：IPv4 用 32 位二进制（4 个字节）表示，IPv6 扩容到了 128 位。
* 整个地址拆成两段：网络号（net-id）指明“你在哪个小区（网络）”，主机号（host-id）指明“你是小区里哪一户（主机）”。
* 常用的传统分类地址按规模分为 A、B、C 三类，通过第一段十进制数字即可判断属于哪一类，进而确定前几段是网络号、后几段是主机号。 为什么 * 为什么要分网络号和主机号？因为互联网路由器转发数据时，不需要记住全世界每一台主机的地址，只需先根据网络号把数据送到目标网络，再在局域网内根据主机号交给具体主机，从而极大压缩路由表体积。
* 为什么 IPv6 要从 32 位扩充到 128 位？因为 32 位 IPv4 最多只有 232≈42.9 亿个地址，面对全球联网设备早已枯竭，128 位提供 2128 个地址，从根本上解决地址短缺问题。
* 为什么划分 A、B、C 三类？不同组织的主机数量差异极大（超大型机构 vs 中型机构 vs 小型局域网），通过给 A/B/C 类分别分配 8 位、16 位、24 位网络号，来匹配不同规模的网络需求。

特殊 IP 地址

  • 主机号全 0：不指代任何一台具体电脑，只代表“整个网络本身”（网络地址）。
  • 主机号全 1：代表“向该网络里的所有主机同时喊话”（直接广播地址）。
  • 主机号全 0 和全 1 被协议保留作特殊用途，因此在计算一个网络（或子网）中可用主机数时，通常要扣除这两个地址（即 2n−2）。
