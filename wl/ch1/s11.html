1.1 IP 地址的分类与 A/B/C 类范围

第4–6题：IP 地址共有几类、C 类判断、126.16.1.1 属于哪类

【印刷】

4.IP地址共有5类，常用的有（ C ）类，其余留作其他用途。

A.1　B.2　C.3　D.4

5.以下哪个IP地址属于C类地址？（ BC ）（多选）。

A.10.2.3.4　B.202.38.214.2

C.192.168.214.2　D.224.38.214.2

6.126.16.1.1是（ A ）类地址。

A.A　B.B　C.C　D.D

【老师手写】

“5类”下方：A,B,C,D,E；上方：掌握A,B,C
A 选项旁：A类；D 选项旁：D类
右上：第1个十进制数
A　1~126　1:3
B　128~191　2:2
C　192~223　3:1

整理

IP 地址分 A、B、C、D、E 五类，常用的是 A、B、C 三类（第4题选 C）。判断类别只看第 1 个十进制数：

  • A 类：1~126，网络号:主机号 = 1 字节 : 3 字节（老师写的“1:3”）
  • B 类：128~191，2 字节 : 2 字节（“2:2”）
  • C 类：192~223，3 字节 : 1 字节（“3:1”）

第5题：10 属于 A 类，202、192 属于 C 类，224 属于 D 类，所以选 BC。第6题：126 落在 1~126，是 A 类。

讲解

  • 直观意思：把 IP 地址想象成“邮编（网络号）+ 门牌号（主机号）”。A 类邮编最短（1 字节）、门牌号最长（3 字节），适合超大型网络；B 类各占一半（2:2）；C 类邮编最长（3 字节）、门牌号最短（1 字节），适合小型局域网。拿到地址直接盯住第 1 个数就能秒判类别。
  • 为什么：传统分类并不是人为随便定界，而是按首字节最高的几个固定二进制位切分的：
    • A 类最高位固定为 0：00000000(0) ~ 01111111(127)，去掉全 0（本网络）和 127（本地回环测试），可用范围就是 1–126。
    • B 类高两位固定为 10：10000000(128) ~ 10111111(191)。
    • C 类高三位固定为 110：11000000(192) ~ 11011111(223)。
    • D 类高四位固定为 1110：224–239（组播）；E 类高四位固定为 1111：240–255（保留）。

第13题：B 类地址用几位标识主机

【印刷】

13.B类地址中用（ C ）位来标识网络中的一台主机。

A.8　B.14　C.16　D.24

整理

B 类是“2:2”：前 16 位网络号，后 16 位主机号，所以用 16 位标识主机，选 C。
