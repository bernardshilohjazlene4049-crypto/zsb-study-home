2.6 网络地址 = IP 地址 AND 地址掩码（CIDR 例）

知识点讲解视频（1）
  • 2.6 网络地址 = IP 地址 AND 地址掩码（CIDR 例） 1:33

【例】已知 IP 地址是 156.16.32.7/20，求网络地址

【印刷】

网络地址 = (IP 地址) AND (地址掩码)

【例】已知 IP 地址是 156.16.32.7/20。求网络地址。

【老师手写】

左上角：笔【红色，写在 logo 下方】
主机号位数 = 32 − 20 = 12
地址掩码：255.255.11110000.0 = 255.255.240.0
网地 = 156.16.32.7 AND 255.255.240.0
　　 = 156.16.32.0/20（“32”下划线，“/20”红）
竖式：
　　　32　00100000
AND 240：11110000
　　　　──────
32 ⇐　　00100000
右侧红字：问：怎么看 /20 【中间两三个字看不清】是网地还是主机IP？
网地～主机号全0，【后面一小段看不清】
主机地址～主机号不变，【后面一小段看不清】
主机号所对应位全0 ⇒ 网地

整理

步骤：

  1. 主机号位数 = 32 − 20 = 12；
  2. 掩码：前 20 位全 1 → 255.255.11110000.0 = 255.255.240.0；
  3. 网络地址 = IP AND 掩码：只有第 3 字节需要算，32 = 00100000，AND 11110000 = 00100000 = 32；第 4 字节 AND 0 = 0。得 156.16.32.0/20。

右侧老师提了一个判断问题：看到“地址/20”，它是网络地址还是主机 IP？老师的结论：主机号对应的位全 0 ⇒ 网络地址（“网地～主机号全0”）；主机地址是“主机号不变，其余全 0”（与 3-7-2、3-7-3 的“主机地址”写法一致）。

讲解

  • 直观意思：把 IP 地址和地址掩码对齐做按位与（AND）运算，就能把主机号抹成 0，把网络前缀原样留下来。
  • 为什么有效：按位与规则是“有 0 则 0，全 1 才 1”。地址掩码的构造规则是“前缀全 1、主机号全 0”：任何位与 1 做 AND 保持原值（保留前缀），任何位与 0 做 AND 强制归零（清空主机号）。
  • 怎么区分 /20 前面写的是网地还是主机 IP：直接把 IP 拆成二进制，只看最后 32 - 20 = 12 位（主机号对应位）——全为 0 就是网络地址；如果这 12 位不全为 0 且不全为 1，就是普通主机 IP；全为 1 则是直接广播地址。
