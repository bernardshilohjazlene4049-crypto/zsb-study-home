整理

CIDR 地址块 = 网络前缀都相同的一段连续地址。156.16.32.0/20：前 20 位相同，主机号 12 位，共 2^12 = 4096 个地址。

  • 最小地址 156.16.32.0：主机号全 0 → 网络地址（“网地”）；
  • 最大地址 156.16.47.255：主机号全 1 → 广播地址（“广地”）；
  • 最小主机 IP = 网络地址 + 1（…00000001，即 156.16.32.1）；最大主机 IP = 广播地址 − 1（…11111110，即 156.16.47.254）；
  • 可指派的地址数 = 2^12 − 2（去掉网络地址和广播地址）。

（把 32.1、47.254 和 2^12 − 2 = 4094 写出来是整理者按原图二进制行换算的，原图只画了二进制行。）

第 3 字节：32 = 0010 0000，47 = 0010 1111，前 4 位 0010 是前缀的一部分，后 4 位和第 4 字节一起是主机号。

讲解

把前 20 位钉死不动，后 12 位从“全 0”一路加 1 数到“全 1”，得到的一整串连续 IP 就是一个地址块： * 第 1 个（全 0）：网络地址（代表整个网段，不能分给电脑）。
* 第 2 个到倒数第 2 个：可以真正配给主机的可用 IP（最小主机 IP 到最大主机 IP）。
* 最后 1 个（全 1）：直接广播地址（给本网段所有主机群发消息用，不能分给单台电脑）。 * 后 12 位每一位有 0 和 1 两种取值，根据乘法原理，总共能组合出 212=4096 个地址。
* 掐头（主机号全 0 的网络地址）去尾（主机号全 1 的直接广播地址），剩下能指派给主机的数量必然是 2主机号位数−2。

【老师手写】

左侧：2^10 = 1024；2^11 = 2048；2^12 = 4096；2^13 = 8192
“156.16.32.0/20”绿色框起；前三个字节（前 20 位）红线下划线
“最小地址”旁：主机号全0，其下：网络地址（红）
“最大地址”旁：主机号全1，其下：广播地址（红）
第2行旁黑字：最小主机IP；倒数第2行旁黑字：最大主机IP
右上：IP数 = 2^主机号位数 = 2^(32−20) = 2^12（“主机号”为手写简写，按上下文读）
“可指派的地址数是 2^12 − 2 个”旁：可用IP数；其下一词【潦草，疑为“主机数”】

整理

与 2-5-1 同一页，这一版老师把用词写清楚：

  • 最小地址 = 主机号全 0 = 网络地址；最大地址 = 主机号全 1 = 广播地址；
  • 地址总数（IP 数）= 2^主机号位数 = 2^(32−20) = 2^12 = 4096；
  • 可指派的地址数 = 可用 IP 数（疑为“主机数”）= 2^12 − 2。

左侧 2 的幂表（2^10 = 1024、2^11 = 2048、2^12 = 4096、2^13 = 8192）是老师给的速查，方便口算。
