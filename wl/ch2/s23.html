2.3 已知地址求地址块

典型题：140.120.84.24/20 的最小/最大地址、掩码、地址数、相当于多少个 C 类

【印刷】

典型题　已知地址块中的一个地址是140.120.84.24/20。试求这个地址块中的最小地址和最大地址。地址掩码是什么？地址块中共有多少个地址？相当于多少个C类地址？

【老师手写】

左上圈：笔
84 上方：→0101
“地址块”框出；“C类地址”下方：C类网络
(1) 主机号位数=32-20=12
(2) 地址块中的 最小地址：140.120.0101 0000.00000000 = 140.120.80.0/20
　　　　　　　 最大地址：140.120.0101 1111.11111111 = 140.120.95.255/20
(3) 地址掩码：255.255.11110000.0 = 255.255.240.0
(4) 地址块中的地址数 = 2^主机号位数 = 2^12 = 4096个
(5) 一共有多少个IP地址 / 一个C类网络中的IP数 = 2^12 / 2^8 = 2^(12-8) = 2^4 = 16个

整理

步骤：

  1. 主机号位数 = 32 − 20 = 12。
  2. 84 = 0101 0100，前缀 20 位 = 140.120 + 0101。主机号 12 位全 0 → 最小地址 140.120.80.0；全 1 → 最大地址 140.120.95.255。
  3. 掩码：前 20 位全 1 → 255.255.240.0。
  4. 地址数 = 2^12 = 4096。
  5. 一个 C 类网络有 2^8 = 256 个地址，4096 ÷ 256 = 2^4 = 16 个 C 类。
