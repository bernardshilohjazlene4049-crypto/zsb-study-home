原型题：4000B 数据报经 MTU=1500B 的网络，分几片（分析图）

【印刷】

原型题

一个数据报长度为4000字节（固定首部长度）。现在经过一个网络传送，但此网络能够传送的最大数据长度为1500字节。试问应当划分为几个短些的数据报片？各数据报片的数据字段长度、片偏移字段和MF标志应为何数值？

（“现在经过一个网络传送，但此网络能够传送的最大数据长度为1500字节。”和“几个短些的数据报片”黄色高亮）

【老师手写】

左上角：笔（红圈）
“固定首部长度”上方：20B（紫）；右上：MTU = 1500B
左侧：分析
上图“数据报”：红框，左小格“首”、右大格“数”；整体括 4000B（紫括号）；首部 20B（紫）；数据部分括 3980B（绿）
下图“数据报片”：左小格“首”、右大格“数”；数据部分括 1480B（绿）；整体括 1500B；其下 MTU（黑）；从“首”到上图首部有箭头连线
右侧：需要 3 辆车【红，“3 辆车”】；3980 ÷ 1480 = 3
类比例子：一共 3980 人；一辆车乘客最多 1480 人

整理

分析：数据报总长 4000B，固定首部 20B，所以数据部分 4000 − 20 = 3980B。网络能传的最大数据长度（MTU）= 1500B，每个数据报片也要带 20B 首部，所以每片的数据字段最多 1500 − 20 = 1480B。

3980 ÷ 1480 ≈ 2.69，要装完必须 3 片（老师写“3980÷1480 = 3”，即进一取整为 3；“进一取整”的说法为整理者补充）。

老师的类比：数据 = 乘客（共 3980 人），一片 = 一辆车（最多坐 1480 人），首部 20B 相当于司机（“司机”类比在 4-2-1 中老师也用过）。具体每片的数据字段长度、片偏移和 MF 见 4-3-2。

原型题解答：各数据报片的数据字段长度、片偏移、MF

【印刷】

原型题

一个数据报长度为4000字节（固定首部长度）。现在经过一个网络传送，但此网络能够传送的最大数据长度为1500字节。试问应当划分为几个短些的数据报片？各数据报片的数据字段长度、片偏移字段和MF标志应为何数值？

（“数据字段长度”“片偏移字段和MF标志”下有紫色下划线）

【老师手写】

左上角：笔（红圈）
左：IP数据报　首｜数　4000B　首部 20B　数据部分 ?=3980
　　数据报片　首｜数　首部 20B　数据部分 1480B　整体 1500B
　　类比例子：一共 3980人　一辆乘客 1480人 车【末尾一字不清，按“车”读】
右：解：固定首部长度 20B
　　IP数据报数据字段长度：4000 − 20 = 3980B
　　数据报片　″　″　　　：1500 − 20 = 1480B
　　3980 ÷ 1480 = 3
　　　　　数据字段　片偏移　MF
　　数据报片1　1480B　0/8 = 0　1
　　　″　″　2　1480B　1480/8 = 185　1
　　　″　″　3　1020B　2960/8 = 370　0

整理

解题步骤：

  1. 固定首部 20B → 数据报数据字段 4000 − 20 = 3980B；每片数据字段最多 1500 − 20 = 1480B；3980 ÷ 1480 → 3 片。
  2. 各片：片 1 数据 1480B，片偏移 0/8 = 0，MF = 1（后面还有）；片 2 数据 1480B，片偏移 1480/8 = 185，MF = 1；片 3 数据 3980 − 1480 − 1480 = 1020B，片偏移 2960/8 = 370，MF = 0（最后一片）。
  3. 片偏移 = 该片数据在原数据里的起始字节数 ÷ 8（与 4-2-1 一致；起始字节数 0、1480、2960 是累加得来的）。

（1020B 为老师手写结果，3980 − 1480 − 1480 = 1020 的验算为整理者补充。）

讲解

直观意思 * 坐车类比（材料核心直觉）：原数据报总重 4000B，但其中 20B 是“车头（固定首部）”，真正要运送的“乘客（数据部分）”是 4000−20=3980 人。前面道路限行（MTU = 1500B），每辆分片小车也必须自带 20B 的车头，所以每辆车最多只能坐 1500−20=1480 个乘客。3980 个乘客分批坐车，前两辆坐满 1480 人，第三辆坐剩下的 1020 人，总共需要 3 辆车（3 个数据报片）。
* 片偏移：标记这一片里的第一个字节，在原数据里排在第几位，但记账单位是 8 字节，所以要除以 8。
* MF（More Fragment）：意思是“后面还有没有分片”。只要后面还有片，就填 1；到了最后一片，后面没了，就填 0。 为什么 * 为什么每个分片都要减掉 20B 固定首部？因为每个分片都是一个独立在网络里传输的 IP 数据报，都必须携带完整的 20 字节 IP 首部（含源/目的 IP、标识、片偏移、MF 等），路由器才能把它们各自送达目的地并重新拼装。
* 为什么片偏移一定要除以 8，且除最后一片外，前面每片的数据字段长度都必须是 8 字节的整数倍？因为 IPv4 首部里“总长度”占 16 位（最大表示 65535 字节），而“片偏移”字段只分配了 13 位（只能表示 213=8192 个数）。为了用 13 位覆盖 65536 字节的定位范围，协议规定片偏移的单位是 8 字节（8192×8=65536）。本题中 1480÷8=185 刚好整除，所以可以直接按 1480B 装满。
* 为什么最后一片的 MF = 0？接收端重组分片时，需要知道原数据报到底在哪里结束，看到 MF = 0 就知道“这是最后一片”，结合它的片偏移和数据长度就能确定原始总长度。
