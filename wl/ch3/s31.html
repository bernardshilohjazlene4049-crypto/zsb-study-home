3.1 把地址块等分成若干子网

知识点讲解视频（1）
  • 3.1 把地址块等分成若干子网 1:32

典型题：136.23.12.64/26 划分为 4 个一样大的子网

【印刷】

典型题　某单位分配到一个地址块136.23.12.64/26。现在需要进一步划分为4个一样大的子网。试问：

(1)每个子网的网络前缀有多长？

(2)每一个子网中有多少个地址？

(3)每一个子网的地址块是什么？

(4)每一个子网可分配给主机使用的最小地址和最大地址是什么？

【老师手写】

左上圈：笔
(1) 28位　(2) 2^(32-28)=2^4=16个
右侧树：/26 136.23.12.01 → 2^(32-26)=64个；/27 分 0、1 → 32个；/28 分 0 1 0 1 → A B C D，16个
(3) 子网地址块
A: 136.23.12.0100 0000=136.23.12.64/28
B: 136.23.12.0101 0000=136.23.12.80/28
C: 136.23.12.0110 0000=136.23.12.96/28
D: 136.23.12.0111 0000=136.23.12.112/28
(4) (+1) 最小主机IP: 136.23.12.0100 0001=136.23.12.65/28
　 (+14) 最大主机IP: 136.23.12.0100 1110=136.23.12.78/28
B → 最小：136.23.12.81/28　最大：136.23.12.94/28
C → 最小：136.23.12.97/28　最大：136.23.12.110/28
D → 最小：136.23.12.113/28　最大：136.23.12.126/28

整理

  1. 分 4 个一样大的子网 = 再借 2 位（2^2 = 4），前缀 26 + 2 = 28 位。
  2. 每个子网 2^(32−28) = 16 个地址。
  3. 第 4 字节 64 = 01 000000，前 2 位 01 是原前缀；接下来 2 位 00/01/10/11 就是 A/B/C/D，得到 .64、.80、.96、.112（都是 /28）。
  4. 主机号全 0 是网络地址、全 1 是广播地址，都不能分给主机：最小 = 网络地址 + 1，最大 = 网络地址 + 14。
子网地址块最小主机地址最大主机地址
A136.23.12.64/28.65.78
B136.23.12.80/28.81.94
C136.23.12.96/28.97.110
D136.23.12.112/28.113.126

讲解

  • 直观意思：把一块大蛋糕均匀切成 N 等份，因为计算机只能对半切（切 1 刀变 2 块，切 2 刀变 4 块，切 3 刀变 8 块），所以必须找一个不小于 N 的最小 2k，从原主机位高位“借”出 k 位当作子网号。
  • 为什么：借出 k 位后，这 k 位可以产生 2k 种组合，正好给最多 2k 个子网编号；每借 1 位，前缀长度加 1，可用主机位减 1，每个子网的容量刚好缩减为原来的一半。
