3.5 从两级到三级：子网号、子网掩码与网络地址

划分子网（P99）：两级 → 三级，子网掩码与各号位数

【印刷】

划分子网（P99）

IP地址 ::= {<网络号>, <主机号>}

IP地址 ::= {<网络号>, <子网号>, <主机号>}

【老师手写】

左侧：两级；三级
两级一行的“主机号”椭圆圈出，上方短词【疑为“主机号”】；右上：默认子掩（默认子网掩码）
红箭头：从“主机号”圈分叉，指向三级一行的“子网号”（旁注：高位）和“主机号”（旁注：低位）；另一红箭头从“网络号”指向三级的“网络号”
三级一行三段下红波浪线，依次标：全1（网络号）、全1（子网号）、全0（主机号）
左下“子掩：”（子网掩码）：
主机号位数 = 子掩中0的个数
网络号位数 = 看是n类IP【“n”字不确定，按“几类IP”读】
右侧：子网号位数 = 32 − 网络号 − 主机号

整理

划分子网 = 把原来两级的“主机号”拆成两段：高位变成子网号，低位仍是主机号（两级 → 三级）。子网掩码里：网络号全 1、子网号全 1、主机号全 0。

三个位数的算法（老师手写）：

  • 主机号位数 = 子网掩码中 0 的个数；
  • 网络号位数 = 看是几类 IP（A 类 8、B 类 16、C 类 24——数值见 1-1-1 的“1:3、2:2、3:1”，整理者按此换算）；
  • 子网号位数 = 32 − 网络号位数 − 主机号位数。

讲解

直观意思 * 原本的 IP 只有两级（小区号 + 门牌号）。划分子网就是把原来的“门牌号（主机号）”从左边（高位）切出一截，改造成“楼栋号（子网号）”，剩下的右边（低位）继续做“房间号（新主机号）”，从而变成三级结构：网络号 + 子网号 + 主机号。
* 子网掩码就像一把“透视尺”：尺子上写 1 的部分对应网络号和子网号，写 0 的部分对应主机号。只要数清子网掩码里有几个 0（主机号位数），再看 IP 是 A/B/C 哪一类（网络号位数），拿 32 一减就能反推出借了多少位做子网号。 为什么 * 为什么要划分子网？如果不划分，一个 B 类网络有 65534 个主机号，全部塞在同一个物理局域网里既浪费地址，又会导致广播风暴且难以管理；划分子网可以在不向互联网申请新网络号的前提下，把内部大网拆成多个小网。
* 为什么必须从原主机号的高位借位做子网号？因为子网掩码要求连续的 1 在左侧、连续的 0 在右侧，这样路由器才能通过一次简单的按位与运算快速截取出网络前缀（网络号+子网号）。
* 为什么公式 子网号位数 = 32 - 网络号 - 主机号 成立？因为 IPv4 总长度恒定为 32 位，且划分子网只动内部主机位、不改变原网络号长度，三者位数之和严格等于 32。

IP 地址的各字段和子网掩码：145.13.3.10 的例子

【印刷】

IP 地址的各字段和子网掩码

两级 IP 地址：net-id｜host-id　　145 . 13 ｜ 3 . 10

三级 IP 地址：net-id｜subnet-id｜host-id　　145 . 13 ｜ 3 ｜ 10

子网号为 3 的网络的网络号　　主机号

子网掩码：1111111111111111｜11111111｜00000000

子网的网络地址：145 . 13 ｜ 3 ｜ 0

【老师手写】

左上角红圈内一个字【疑为“笔”】
“145”下波浪线；“host-id”红圈
“subnet-id”上方：8位
子网掩码：左侧“子掩：”（“子网掩码”下划线）
掩码下方标注：16位（网络号一段）；32−16−8（子网号一段）；8位（主机号一段）
“子网的网络地址”红圈

整理

同一个地址 145.13.3.10 的两种看法：

  • 两级：net-id = 145.13，host-id = 3.10；
  • 三级：net-id = 145.13（16 位），subnet-id = 3（8 位），host-id = 10（8 位）。

子网掩码：网络号 16 位全 1 + 子网号 8 位全 1 + 主机号 8 位全 0，即 255.255.255.0（此点分十进制为整理者换算，原图只画了二进制）。子网的网络地址：主机号清零，得 145.13.3.0。老师在子网号下写“32−16−8”，说明 8 位子网号是这样得到的（32 − 网络号 16 − 主机号 8）。

讲解

直观意思 * 拿 145.13.3.10 这条 B 类地址举例：
* 没划子网时，前两段 145.13 是网络号，后两段 3.10 都是主机号。
* 划了子网、给出子网掩码（24 个 1 + 8 个 0，即255.255.255.0）之后：末尾有 8 个 0，说明新主机号占 8 位；B 类原网络号占 16 位；中间剩下的 32 - 16 - 8 = 8 位就是子网号。
* 于是第三段 3 被划给了子网号，最后一段 10 才是主机号。把主机号 10 清零，就得到了它所属的子网网络地址 145.13.3.0。 为什么 * 从外面看 145.13.3.10 这串数字本身，根本看不出它有没有划分子网、子网号占几位；只有配合已知的子网掩码，才能精准划出网络前缀与主机号的边界。
* 用老师的方法验算一遍：32 - 16 - 8 = 8 位，直接印证了上一页 37_p64 的万能公式 子网号位数 = 32 - 网络号 - 主机号。

网络地址 = (IP 地址) AND (子网掩码)：141.14.72.24，掩码 255.255.192.0

【印刷】

网络地址=(IP 地址) AND (子网掩码)

三级 IP 地址：net-id｜subnet-id｜host-id

逐位进行 AND 运算

子网掩码：1111111111111111｜11111111｜00000000（此行与 3-5-2 同图）

子网的网络地址：net-id｜subnet-id｜00000000

【例】已知 IP 地址是 141.14.72.24，子网掩码是 255.255.192.0。试求网络地址。

【老师手写】

左上角：笔（红圈）
右上：0 AND 1 → 0；1 AND 1 → 1（两条箭头）；其下竖式 72 − 64 = 8
网地 = IP AND 子掩
　　 = 141.14.72.24 AND 255.255.192.0
　　 = 141.14.64.0（“64”红色下划线）
竖式：
　　 72：01001000
AND 192：11000000
　　　　 ────────
64 ⇐　　01000000

整理

掩码 255.255.192.0：第 3 字节 192 = 11000000，只保留前 2 位。

第 3 字节：72 = 01001000，AND 11000000 = 01000000 = 64；第 4 字节 AND 0 = 0；前两字节 AND 255 原样保留。所以网络地址 141.14.64.0。

右上 72 − 64 = 8：72 = 64 + 8，用来把 72 拆成二进制 01001000（拆法为整理者推测）。

讲解

直观意思 * 把 IP 地址和子网掩码上下对齐，按二进制一位一位做“逻辑与（AND）”运算，就能直接算出子网的网络地址。
* AND 运算的直观效果就像“滤网”：
* 掩码是 1 的位置（255），原样放行（0 AND 1 = 0，1 AND 1 = 1）；
* 掩码是 0 的位置（0），一律强制归零（任何数 AND 0 = 0）；
* 掩码既不是 255 也不是 0 的那个“分界字节”，拆成 8 位二进制逐位做 AND 即可。 为什么 * 网络地址的定义就是“保留网络号和子网号不变，把主机号全部置为 0”。
* 恰好子网掩码把网络号和子网号全设为 1、主机号全设为 0，再结合布尔代数“与 1 得原值、与 0 得 0”的特性。
