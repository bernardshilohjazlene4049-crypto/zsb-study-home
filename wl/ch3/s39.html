P101【典型习题】：C 类分 8 个子网的掩码；同一子网 AND 结果

【印刷】

P101【典型习题】

1.某部门申请到一个C类IP地址，若要分成8个子网，其掩码应为（　　）

A.255. 255. 255. 255　　　　B.255. 255. 255. 0

C.255. 255. 255. 224　　　　D.255. 255. 255. 192

2.若两台主机在同一子网中，则两台主机的IP地址分别与它们的子网掩码相“与”的结果一定（　　）

A为全0　　B为全1　　C相同　　D不同

【老师手写】

第1题括号内：C（紫圈）；选项 C 的“224”圈出
第1题上方：红：2^n − 2 ≥ 8 ⇒ n = 4
　　　　　　紫：2^n ≥ 8 ⇒ n = 3
第2题括号内：C（紫圈）
第2题下方（红）：网络地址 = IP AND 掩码

整理

第1题：老师圈的答案是 C（224）。224 = 11100000，子网号 3 位，2^3 = 8 个子网。老师在题上写了两行：红字 2^n − 2 ≥ 8 ⇒ n = 4；紫字 2^n ≥ 8 ⇒ n = 3（不减 2，掩码 224，选 C）。

第2题：同一子网内的主机，网络地址相同，网络地址 = IP AND 掩码，所以结果一定相同，选 C。

讲解

  • 直观意思： 求“至少需要借几位 n 来当子网号”时，考试中会出现两个口径：
    1. 严格/传统口径（2n−2≥所需子网数）：去掉全 0 和全 1 两个子网，取满足条件的最小整数 n；
    2. 宽松/现代口径（2n≥所需子网数）：全 0 和全 1 子网都允许使用，取满足条件的最小整数 n。
  • 为什么： 早期分类路由标准（RFC 950）担心全 0 子网与主类网络地址混淆、全 1 子网与主类广播地址混淆，规定子网号不能为全 0 和全 1，所以要减 2；后来现代路由协议与无分类编址（RFC 1878 / CIDR）支持携带掩码转发，不再歧义，全 0 和全 1 子网均可使用，故无需减 2。

第4题：197.99.222.139，掩码 255.255.255.240，求地址类、网络地址、主机地址、广播地址

【印刷】

4.已知 IP 地址 = 197.99.222.139，子网掩码 = 255.255.255.240

地址类 ________　　网络地址 ________

主机地址 ________　　广播地址 ________（主机号都为1）

【老师手写】

地址类：C（“197”红线下划线）
网络地址：197.99.222.128；网络地址左上有红括号和一词【看不清，疑为“网地公式”】
主机地址：0.0.0.11
广播地址：197.99.222.143；其上标注：（直接）
下方：197.99.222.1000｜1011（“1000”紫色）
右上：139：1000｜1011；AND 240：1111 0000；128 ⇐ 1 0000000
左上：10 → 1010；11 → 1011；两行上方各有一个小标记【看不清】

整理

掩码 240 = 1111 0000：主机号 4 位。139 = 1000 1011：前 4 位 1000 是子网号，后 4 位 1011 是主机号。

  • 地址类：197 在 192~223 → C 类；
  • 网络地址：139 AND 240 = 1000 0000 = 128 → 197.99.222.128；
  • 主机地址：只留主机号 1011 = 11 → 0.0.0.11（与 3-7-2、3-7-3 的“主机地址”写法一致；左上 10 → 1010、11 → 1011 是老师写的二进制对照，用于把主机号 11 与 1011 对应，用途为整理者推测）；
  • 直接广播地址：主机号全 1 → 1000 1111 = 143 → 197.99.222.143。

讲解

  • 直观意思： 先保持网络号和子网号不变，把主机号对应的二进制位全部填成 1，得到的就是该子网的直接广播地址。它是整个子网里的最后一个（数值最大）地址。
  • 为什么： 在 IPv4 协议约定中，一个子网内主机号全 0 用来代表“本网络/本子网本身”（网络地址），主机号全 1 用来代表“向该子网内所有主机群发消息”（直接广播地址）。因此这两个极端地址都不能分配给具体主机，这也是每个子网可用主机数必须用 2m−2 计算的原因。
