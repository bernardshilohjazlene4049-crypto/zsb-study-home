3.3 点对点链路与 /31 地址块

  • 3.3 点对点链路与 /31 地址块 1:35

注意：路由器直连链路可用 /31

【印刷】

注意：

两个路由器直接相连的接口处，可指明也可不指明 IP 地址。如指明 IP 地址，则这一段连线就构成了一种只包含一段线路的特殊“网络”。这种网络仅需两个 IP 地址，可以使用 /31 地址块。主机号可以是 0 或 1。

LAN2 1.1.1.8/29：1.1.1.9、1.1.1.10、1.1.1.11、1.1.1.12、1.1.1.13（标注：网络地址、IP地址）

LAN3 1.1.1.16/29：1.1.1.17、1.1.1.18、1.1.1.19

N1 1.1.1.24/31：1.1.1.24、1.1.1.25

N2 1.1.1.26/31：1.1.1.26、1.1.1.27

N3 1.1.1.28/31：1.1.1.28、1.1.1.29

【老师手写】

/31 ⇒ 主机号位数=32-31=1位
“仅需”二字红色

整理

两台路由器直连的那段线路如果配 IP，就算一个只有两个地址的特殊网络，用 /31：主机号只有 32 − 31 = 1 位，取 0 或 1，正好两个地址。

图中三条路由器间链路：N1 1.1.1.24/31（.24、.25）、N2 1.1.1.26/31（.26、.27）、N3 1.1.1.28/31（.28、.29）；三个局域网都是 /29。

讲解

  • 直观意思：一个网段里，最开头那个地址代表“整个网段本身”（网络地址），最末尾那个地址用来“朝全网喊话”（广播地址），常规情况下这俩地址不能分给具体电脑用，所以“可用主机数”要减 2。但遇到 /31（路由器间点对点直连）和 /32（单台主机路由）属于特例，不能死套减 2。
  • 为什么：主机位全 0 用来标识网络本身，主机位全 1 用于本网段广播。但在只有两端的点对点链路上根本不需要区分“广播”和“单播”，因此 RFC 3021 允许 /31 的两个地址直接分给链路两端接口使用。
    • 点对点链路都是“只留最后 1 位主机位（21=2 个地址给两端）”：IPv4 总长 32 位，留 1 位就是 /31；IPv6 总长 128 位，留 1 位就是 /127。别把俩数字张冠李戴。
