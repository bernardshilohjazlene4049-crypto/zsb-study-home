⚡ 考前一口气 8 条必背铁律

  1. 编译运行 4 步曲：编辑（.c）→ 编译（每个 .c 出一个 .obj）→ 链接（整个项目出一个 .exe）→ 执行；注释在编译前的预处理阶段被替换为一个空格；main 函数唯一且位置任意，程序总从 main 开始到 main 结束。
  2. 标识符与 5 个必背 ASCII：只能由字母、数字、下划线组成，不能数字开头，不能用全小写关键字（Int 合法，sizeof 是关键字）；必背 ASCII：'\0'=0、空格 ' '=32、'0'=48、'A'=65、'a'=97（大小写相差 32）。
  3. 表达式优先级绝杀口诀：「张飞算计关羽获得血条恢复战斗」→ 括号 → !单目 → 算数 → 关系 → 与(&&) → 或(||) → 条件(?:) → 赋值(=) → 逗号(,)；三大右结合：单目、条件（三目）、赋值！
  4. 表达式 3 大高频雷区：① 指数 e 前后必有数且 e 后必为整数；② 取余 % 前后必须全是整数（负数余数符号跟左边被除数）；③ 赋值 = 左边必须是可修改的左值（变量），复合赋值拆解右边整体加括号。
  5. 输入输出与控制语句 4 条铁律：double 用 scanf("%lf")、printf("%f")；scanf 可写域宽（%3d）绝不能写小数位（%3.2f 错）；puts 自动把 \0 变 \n 换行；所有控制语句中只有 switch 后必须有 {}、只有 do-while() 后必须有 ;；for 中 continue 先走步进再判条件，while 中 continue 直接判条件！
  6. 数组与字符串 5 条硬规则：定义数组 [] 内必须是常量（不可变量），数组名是地址常量（禁 a++ / 整体赋值）；二维数组初始化只可省行标、绝不可省列标；方阵主对角线 i == j、副对角线 i + j == n - 1；strlen 算 \0 前有效字符数，sizeof 算数组总字节（含 \0）；scanf("%s") 遇空格截断，gets 可读空格。
  7. 函数传参与 static 四维铁律：函数可嵌套调用绝不可嵌套定义，形参每个变量必须写类型；形参没 * 没 [] 就绝不可能改实参（指针传参还须内部对 *x / a[] 改值，且自增必须带括号 (*x)++）；全局 / 静态全局 / 静态局部未初始化全默认 0，唯独普通局部默认是垃圾值；static 局部初始化只执行一次，static 全局仅限本文件禁 extern！
  8. 指针 4B 与二维数组 8 大等价公式：32 位下任何指针本身全占 4B（sizeof(p)==4），指向什么 +1 就跳过什么，void* 未强转禁 * 与 ++；一维数组 *(a+i)==a[i]；二维数组脱 1 层 * 得列地址（*(a+i)==a[i]==&a[i][0]），脱 2 层 * 才得元素值（*(*(a+i)+j)==a[i][j]、**a==a[0][0]、*(*a+j)==a[0][j]）！

1.1 程序、计算机语言发展与 C 语言概述

1. 程序、指令与软件

  • 指令：可以被计算机并的基本操作。
  • 程序：一组计算机能识别和执行的。
  • 软件：与计算机系统操作有关的计算机、规程、，以及可能有的文件、文档及数据。

2. 计算机语言发展的三个阶段

发展阶段语言名称本质与执行方式核心特点与移植性
第一阶段语言进制代码（机器指令），计算机可以执行学、记、推广；具体机器、移植
第二阶段语言机器语言的化；需通过转为机器指令执行比机器语言简单些，仍推广；具体机器、移植
第三阶段语言接近自然语言和数学语言；源程序需通过程序转为目标程序执行功能，依赖于具体机器，可移植性好
  • 高级语言发展的三个阶段：第一阶段 语言 → 第二阶段 语言 → 第三阶段 语言。
  • 必考问答：C 语言属于语言；在高级语言阶段中属于语言；C 语言是面向的语言。

3. C 语言的由来、版本与核心优点

  • 由来：国家 ，实验室 ，开发者：丹尼斯·里奇（注：原讲义简记“使用 Linux 系统设计”，严谨史实为 1972 年用于重写 UNIX 系统，Linux 内核随后也由 C 语言开发）。
  • 两个核心标准版本：（年）、（年）。
  • 优点①：用作为程序的模块单位，便于实现程序的模块化，C 语言是完全模块化和结构化的语言。
  • 优点②：允许直接访问，可以直接对硬件进行操作。
01

必背结论

  • 指令：可以被计算机识别并执行的基本操作命令；程序：一组计算机能识别和执行的指令；软件：程序 + 规程 + 规则 + 文件、文档及数据。
  • 第一阶段机器语言（二进制代码，计算机直接执行，难学难记难推广，依赖具体机器、难移植）；第二阶段汇编语言（机器语言符号化，需汇编程序转换，仍依赖机器、难移植）。
  • 第三阶段高级语言（接近自然语言和数学语言，功能强大，不依赖具体机器，需编译/解释程序转为目标程序）。
  • 高级语言三阶段：非结构化语言 → 结构化语言 → 面向对象语言；C语言 = 高级语言 + 结构化语言 + 面向过程语言。
  • C语言由美国贝尔实验室丹尼斯·里奇设计；两个核心标准版本：C89（1989年）、C99（1999年）。
  • C语言两大优点：用函数作为模块单位（完全模块化和结构化）；允许直接访问物理地址（可直接操作硬件）。
02

解题套路

判语言阶段题：看到“二进制/直接执行”选机器语言；看到“符号化/助记符/汇编程序”选汇编语言；看到“不依赖具体机器/可移植性好/编译转换”选高级语言。

判 C 语言属性题：问大类答“高级语言”，问高级语言阶段答“结构化语言”，问编程范式答“面向过程”（区别于 C++/Java 的面向对象）。

判软件定义题：软件 ≠ 只有程序，必须包含程序、规程、规则以及相关文档和数据。

03

易错点

汇编语言虽然比机器语言易记，但依然属于低级语言，依赖具体机器、难移植，不能被计算机直接执行（必须经汇编程序转换）。

C 语言是“面向过程”的结构化语言，不是面向对象语言。

勘误提示：部分课堂笔记将 C 语言诞生背景简写为 Linux，历史上丹尼斯·里奇在 1972 年是为重写 UNIX 操作系统设计的 C 语言（Linux 内核后来也采用 C 语言编写），考试紧扣“美国贝尔实验室、丹尼斯·里奇、C89/C99”即可。

1.2 C 程序结构、注释规则与《C 语言常识》7 条必背

1. 最简单的 C 语言代码（输出 "halo"）

C 语言代码
#include <stdio.h>
int main() {
    printf("halo");
    return 0;
}
  • 注意：C 语言的一条语句是通过来识别的（每条执行语句末尾必须加英文分号）。

2. 注释规则与两种方式

  • 处理时机：在计算机编译 C 语言程序之前的阶段进行处理，将所有的注释替换为，所以在代码执行时计算机看不到注释。
  • 第一种（单行注释）：使用，表示当前行从 // 之后都是注释内容。
  • 第二种（多行注释，C89 支持）：使用和从代码中分割出注释，从 /* 开始到 */ 之内为注释，也叫“”（注意不可嵌套）。
  • 注释的两种使用场景：程序员自己查看（提高可读性）、将暂时不需要运行的代码注释掉（调试排错）。

3. 《C 语言常识》7 条必须背

  • ① 一个程序由源程序文件组成。
  • ② 源程序文件也叫、，就是文件。
  • ③ 源程序文件包括：、、。
  • ④ 一个 C 语言程序是由函数组成的（是 C 程序的主要组成部分）。
  • ⑤ 一个程序必须包含唯一个函数（main 函数可以写在 C 文件的位置）。
  • ⑥ 程序中被调用的函数可以是系统提供的函数，也可以是函数。
  • ⑦ 程序总是从函数开始执行的，即从函数开始执行，到函数结束时程序就结束。
01

必背结论

  • C 语言的一条语句是通过分号（;）来识别的（不是靠回车换行）。
  • 注释在编译之前的预处理阶段处理，将所有注释替换为一个空格，代码执行时计算机看不到注释。
  • 单行注释：//（从 // 到本行末）；多行注释（C89 支持，又称块注释）：/* ... */（不可嵌套使用）。
  • 《C 语言常识》①~③：程序由一个或多个源程序文件（源文件/源程序，即 .c 文件）组成；源文件包含预处理指令、全局声明、函数定义。
  • 《C 语言常识》④~⑥：C 程序由一个或多个函数组成（函数是主要组成部分）；必须包含唯一一个 main 函数（可写在文件的任意位置）；可调用库函数或用户自定义函数。
  • 《C 语言常识》⑦：程序总是从 main 函数开始执行，到 main 函数结束时程序就结束（与 main 函数书写位置无关）。
02

解题套路

判注释题：一查阶段（编译前的预处理阶段，替换为一个空格，不是直接删空导致前后标识符粘连）；二查写法（单行 //，多行 /* ... */ 且 /* 不能套 /*）。

判 main 函数题：牢记“唯一 1 个 + 位置任意 + 始终从 main 开始、到 main 结束”。

判语句边界题：分号 ; 是一条语句结束的唯一标志，一行可写多条语句，一条语句也可拆多行。

03

5.1 真假判定（0<a<2 陷阱）与 if 单/双/多分支

1. 真与假（数值真假 / 关系真假 / 逻辑真假）

  • 数值真假：0 表示，不是 0 的数都表示。
  • 关系/逻辑值：用代表真、对、正确、成立；用表示假、错、不成立。
  • 数字参与逻辑运算：非 0 表示，0 表示。
  • 必考训练：0 < a < 2 的结果永远为（因为 < 左结合，先算 0 < a 只能得 0 或 1，无论 0 < 2 还是 1 < 2 均为真！正确区间判断须写 a > 0 && a < 2）。
  • 逻辑速复：!100=，!0=，!真=，!假=；&& 全为、有为；|| 全为、有为；短路特性：表达式 1 能得出结果则表达式 2被执行。

2.1 ~ 2.3 if 单分支、双分支与多分支

必背结论

  • 数值真假：0 表示假，不是 0 的数（包括负数、小数）都表示真。

  • 高频陷阱题：0 < a < 2 在 C 语言中永远为 1（真）！因为先算 0 < a 得 0 或 1，二者均小于 2；判断区间必须写 a > 0 && a < 2。
  • if 单分支：只关心 1 种情况成立，真执行语句，假跳过不执行。
  • if 双分支：关心 2 种情况（成立与不成立），真执行语句 1，假执行语句 2，然后继续往下执行。
  • if 多分支（if ... else if ... else）：没有 else 表示不关心都不成立的其他情况；表达式从上到下逐一判断，一旦某个为真执行对应语句后直接退出整个 if，后续分支不再检查。

读多分支程序题：从第一个 if 往下判，命中第一个“真”就执行它的语句并立刻划掉下方全部 else if 和 else。

2.4 if 嵌套下划线配对法 与 2.5 语法注意事项

  • 嵌套三大原则：① 一条语句的第一个 if 画一个下划线；② if、else if、else 默认只执行一条语句，若该语句以 if 开头一定是嵌套（多画一个下划线）；③ else、else if 必须与其的 if 进行配对（配对的一对下划线数量一样）。
  • 嵌套做题三步：① → ② → ③ 。
  • 语法①：if 的 ()、表达式、语句均不可省略（若什么都不执行需写）。例：if(a>b); 成立执行空语句、假不执行，当前语句相当于无效占位。

3. 三目运算符回顾 与 【等价题型】代入法

  • 三目运算符 表达式1 ? 表达式2 : 表达式3：1 为真则，1 为假则；相当于 。
  • 多个三目采用结合（先算边的三目），找表达式 1/2/3 采用法，和比优先级，高就归入、低就停止。
  • 【等价题型——代入法 5 步】（以 (exp)?a++:b-- 求与 (exp) 等价的式子为例）：
  • ① 找出待等价的表达式 (exp)；② 思考结果种类（只有真、假）；③ 明确成因（exp 非 0 为真、exp 为 0 为假）；④ 写出代入值（不要绝对取 1，取 exp = 3 为真、exp = 0 为假）；⑤ 将 3 和 0 分别代入 A/B/C/D，结果完全相同即等价（如 exp != 0）。

必背结论

  • if 嵌套配对铁律（下划线配对法）：① 第一个 if 画 1 个下划线，嵌套多 1 个下划线；② else / else if 必须与其之前、最近、且未被配对的 if（或 else if 中的 if）配对；③ 配对的一对下划线数量一样。

  • 【等价题型】代入法 5 步：找出待等价表达式（如 (exp)?a++:b-- 中的 exp）→ 明确只有真/假 → 取非 0 具体值（如 3，不要只取 1！）和 0 → 分别代入 A/B/C/D 选项，结果完全相同即等价。

4. switch 语法结构与 10 条必考要点

C 语言代码
switch (表达式) {
    case 常量1: 语句1; break;
    case 常量2: 语句2; break;
    default:    语句n+1;
}
  • ① switch 后的 ()、表达式、{} 。
  • ② 表达式值类型和 case 后的值必须是 （不能是浮点数）。
  • ③ case 后的值必须是（不能含变量）。

  • switch 语法④~⑥：各 case 值必须互不相同，顺序无所谓；case 值与 default 后必须写冒号 : ；default 位置随意（总是最后一个比较），也可以没有 default。
  • switch 语法⑦~⑧（核心）：穿透特性——匹配进入某冒号 : 后，不再比较后续 case/default，直接依次执行所有语句，直到遇到 break; 或 switch 结束 }；case: 后写多条语句不需要 {}。

2. 【死循环】判定三条件

  • ① 循环条件为永真（如 while(1)）；
  • ② 循环条件有为假的可能，但是没有向假前进的步进（如 i=1; while(i>0) i++;）；
  • ③ 没有可以被执行的 break;。
  • 结论：满足 是死循环，满足 也是死循环。
01

必背结论

  • 循环两大类：已知循环次数 → 用 for；已知循环条件 → 用 while、do-while（三者代码可完全相互转换）。
  • while 循环（先判断后执行）：()、表达式、语句均不可省；默认管 1 条语句（多条用 {}）；最少执行 0 次，最多执行无数次（死循环）。
  • 死循环三条件：① 条件永真；② 条件有假可能但没有向假前进的步进；③ 没有可被执行的 break;（满足 ①③ 或 ②③ 即死循环）。
  • do-while 循环（先执行后判断）：do 与 while 间默认 1 条语句（多条用 {}）；while 后的 ()、表达式、分号 ; 均不可省略！最少执行 1 次，最多无数次。
  • 读程序写结果追踪法：while 按「有关变量、表达式、循环体」列表；do-while 第一次直接跑循环体，第二次起再按三要素追踪。

判死循环题：检查循环体内有没有改变条件变量的步进语句（且方向要朝“假”靠拢），以及有没有 break; 逃生口。

  • for 语法：() 中 3 个表达式用两个分号 ;; 分开；() 和 ;; 不可省略，3 个表达式均可省略；循环体语句不能省略（最少写空语句 ;，如 for(;;);）；默认管 1 条语句，多条用 {}；最少 0 次，最多无数次。
  • 执行顺序（必考）：① 初始操作（进循环仅执行 1 次）→ ② 循环条件（真进④，假退出）→ ④ 循环体 → ③ 步进 → 回到 ② 条件判断。

  • 表达式 3 省略：无步进操作（需在循环体内改变变量，否则易死循环）。
  • 循环体省略（写分号 ;）：循环体为空语句，条件为真时执行空操作后直接走步进。

5. 典型循环编程模板（等差数列累加求和三版本对照）

// ① while 版本
int i = 1, sum = 0;         // 赋初值
while (i <= 99) {           // 终值条件
    sum += i;               // 计算
    i += 2;                 // 步进（与等差有关）
}

// ② do-while 版本
int i = 1, sum = 0;
do {
    sum += i;
    i += 2;
} while (i <= 99);

// ③ for 版本（推荐：结构最紧凑，不易漏步进）
int i, sum = 0;
for (i = 1; i <= 99; i += 2)
    sum += i;

  • 控制语句总结②：所有控制语句中，只有 do-while() 后必须有分号 ;。
  • 控制语句总结③：while、for 先判断后执行（最少 0 次）；do-while 先执行后判断（最少 1 次）。
  • break; 作用：结束当前层循环或当前层 switch（嵌套循环里只跳出所在那一层！）。
  • continue; 作用：结束当前这一次循环，前往下一次循环——在 while / do-while 中直接去判断表达式；在 for 中直接前往步进③，步进完再判条件②！
  • 等差数列循环编程四要素：初值、终值、等差（步进）、计算；累加求和和初值为 0（非等差项先放进和中），推荐优先用 for。

读含 break / continue 的循环题：一标清是 while 还是 for；二遇 continue 在 for 里画箭头指向步进③，在 while 里画箭头指向条件判断；三遇 break 只画箭头跳出当前这一层循环/switch。

C 语言代码

for (i = 0; i < 3; i++) {         for (j = 0; j < 4; j++) {
    for (j = 0; j < 4; j++)           for (i = 0; i < 3; i++)
        printf("%d ", a[i][j]);           printf("%d ", a[i][j]);
    printf("\n");                     printf("\n");
}                                 }

  • ② 一列一列用：大循环是（j），小循环是（i），访问 a[i][j]（循环完一列再下一列）。
  • ③ 主对角线：和相同，每行只有个，只需个 for，操作 a[i][i]。

必背结论

  • 二维数组 数据类型 数组名[行数][列数];：两个常量表达式分别表示行数和列数，物理内存中按行连续一维存储。
  • 《求数据类型》挡住法（例 int a[3][4];）：找定义处把目标挡上，剩下啥就是啥——a 为 int[3][4]（二维数组），a[0] 为 int[4]（第 0 行一维数组名/地址常量，不可赋值），a[0][0] 为 int（整型变量）。
  • 二维数组初始化铁律：按行初始化 {{1,2,3},{4,5,6}} 或连续初始化 {1,2,3,4,5,6}；全部初始化时最多只能省略第一个 [] 中的行数，绝不能省略第二个 [] 中的列数！
  • 行列遍历：一行一行用 → 大循环行标 i、小循环列标 j（a[i][j]）；一列一列用 → 大循环列标 j、小循环行标 i（仍写 a[i][j]）。
  • 主对角线（行数=列数）：行标与列标相同，每行只有 1 个，只需 1 个 for，操作 a[i][i]。
  • 副对角线（行数=列数）：行标 + 列标 = 行数 - 1，每行只有 1 个，只需 1 个 for，操作 a[i][行数 - 1 - i]。

做二维数组初始化合法性题：一眼扫第二个 []（列数）——只要列数空着（如 int a[2][] = ...），立刻判非法！

  • 参数个数陷阱：与 () 中顶层逗号数有关，n 个逗号表 n+1 个参数；func(1, 2, (3, 4)) 只有 3 个参数（第 3 个是逗号表达式 (3,4)，值为 4）。

  • 实参是调用时传入的实际数据，形参是定义时的参数名；调用时参数个数、顺序、类型须匹配。
  • 读程序写结果 4 步法（必考）：① 遇调用直跳定义 → ② 实参给形参赋值 → ③ 执行函数体（有返回值带回调用处，无返回值也回调用处）→ ④ 继续向下执行。

解题套路

写函数定义 4 步法：① 定返回值类型（无返回写 void）；② 起函数名；③ 写形参列表（每个参数都要单独写类型，如 int a, int b，绝不能写成 int a, b！）；④ 写 {} 函数体。

5. 参数传递两种方式：值传递 vs 指针传递

必背结论

  • 函数声明（编译阶段检错）：函数首部 + ;，只不关心参数名（参数名可省略、可改写，如 int haha(int, char); 合法）。
  • 需要声明的两种情况：① 同文件函数调用写在定义之上 → 向前声明（首部 + ;）；② 调用的函数/全局变量在外部文件 → extern 声明外部可用（如 extern int haha(int a);）。
  • 【值传递】：实参值单向赋给形参，函数内修改形参绝不能修改实参。
  • 必背秒杀口诀：形参类型没有 * 也没有 []，就不可能修改实参！
  • 【指针传递】函数内能修改实参的两大必要条件（缺一不可）：① 形参类型必须有 * 或 []；② 函数内部必须对形参取内容 * 或数组元素 [] 进行 ++、--、赋值！

解题套路

秒判函数调用会不会改变 main 中实参值：① 先看形参列表有没有 * 或 []（没有就直接答“不可能改，实参原值不变！”）；② 若有 * 或 []，再看函数体里有没有对 *形参 或 形参[下标] 做赋值/++/--（两个条件同时具备才会修改实参！）。

判函数声明合法题：只核对返回值类型、函数名、各参数类型顺序以及末尾有没有 ;，形参名写不写、叫什么都完全合法！

易错点

见到指针形参就以为一定改了实参：错！如 void f(int *p) { int b=5; p=&b; } 只改了形参指针指向，没有通过 *p 改内容，实参不变！

把 (*x)++ 错写成 *x++：单目右结合下 *x++ 先移指针 x 再取内容，并没有让原整数加 1！必须加括号 (*x)++！

8.3 全局变量、局部变量与 static 静态变量（四维对比 + 就近原则）

6. 四类变量核心对比表（默认值 / 生命周期 / 使用范围，必须背）

变量名称定义位置特征默认值（未赋初值）生命周期使用范围（作用域）
全局变量在所有 {} 之外（可 extern）
局部变量（含形参）在 {} 之内
静态全局变量全局变量前加 static（禁 extern）
静态局部变量局部变量前加 static
  • 形参也可以看成，只能在函数内使用。
  • static 关键字作用：将变量的，同时使全局变量（外部文件不能用 extern 声明静态全局变量）。
  • 读程序核心：static 修饰的静态局部变量定义初始化语句；全局与局部重名时采用。

讲义综合案例逐行填空详解

C 语言代码
int a;                    // 全局变量（默认初值 0）
void haha(void) {
    int y = 7;            // 局部变量（仅 haha 的 {} 内可用）
    static int m = 20;    // 静态局部变量（定义初始化只执行一次，生命周期到程序结束）
    printf("%d", a);      // 用全局变量 a，输出 0
    extern int b;         // 声明其他文件中的全局变量 b
    printf("%d", b);      // 输出外部全局变量 b 的值
}
int main() {
    int a;                // 局部变量（与全局 a 重名，未初始化为垃圾值）
    { int k = 20; }       // k 是块内局部变量，出 {} 即销毁
    // printf("%d", k);   // 错误！超出 k 的作用域，编译报错
    printf("%d", a);      // 按就近原则用 main 的局部 a，输出随机垃圾值
    return 0;
}
  • 对照填空：文件顶层 int a; 是变量，haha 中 printf("%d", a) 用输出；main 中 int a; 是变量，k 是变量，出 {} 打印 k 会，main 打印 a 按就近原则用，输出。
01

必背结论

  • 全局变量（所有 {} 外）：默认值 0，生命周期程序开始到结束，范围整个程序（可 extern 跨文件）。
  • 局部变量（{} 内，含形参）：默认值垃圾值/随机值，生命周期定义开始到 } 结束，范围仅当前 {} 内。
  • 静态全局变量（全局 + static）：默认值 0，生命周期程序开始到结束，范围仅当前文件内（禁止外部用 extern 声明！）。
  • 静态局部变量（局部 + static）：默认值 0，生命周期从定义执行开始到程序结束，范围当前 {} 内；定义初始化语句只执行 1 次！
  • 形参也属于局部变量，只能在所属函数内使用；全局变量与局部变量重名时，采用就近原则（局部优先屏蔽全局）。
02

解题套路

做带 static 读程序写结果题（专升本超高频！）：在 static int x = 初始值; 旁画一颗星——第 1 次调用执行赋初值，第 2、3、... 次调用彻底跳过这句初始化，直接沿用上一次调用离开时 x 留下的值！

做同名变量遮蔽题：在函数内部找有没有同名的局部变量/形参；有就用局部（就近原则），没有才往外找全局变量。

03

易错点

普通局部变量未初始化时默认值是垃圾值/随机值，绝不是 0！（只有全局和 static 变量默认才是 0）。

extern static int b; 属于语法冲突错误！static 锁死仅本文件可见，extern 要跨文件可见，二者水火不容。

代码块 { int k = 20; } 结束后，在花括号外面再使用 k 直接编译报错（超出作用域）。

解题套路

秒判本身类型与指向类型（例 int p;）：挡住 p → 本身类型 int ；挡住 *p → 指向类型 int *。

秒判 p + 1 跨度：先找 p 的指向类型 T，跨过的字节数 = sizeof(T)（如 char *b = (char*)&a; 指向 char，所以 *b 取 1B，b+1 跨 1B）。

写复杂指针声明两步替换：① 先写出目标变量/函数本身；② 把名字换成 (*p) 即可！

03

易错点

以为 double *p 占 8 字节、char *p 占 1 字节：错！32 位考题下所有类型指针本身都是 4 字节（只有 sizeof(*p) 才分别是 8 和 1）！

直接对 void *p 做 *p 或 p++ 编译报错：因为 void* 没有明确指向类型，编译器不知道取几字节、跳几字节，必须先强转如 *(int*)p！

局部指针变量 int *p; 未初始化就写 *p = 10; 会向随机垃圾地址乱写导致崩溃！

六、一维数组与指针（等价公式 + a 与 p 两大区别）

  • int a[10];：a 的类型是 ，是数组的，也是；a[0] 是 类型，故 a == &a[0] 为 类型，表达式中 a 可看作 类型。
  • 两大等价公式：a + 下标 == ；*(a + 下标) == （例 a + 1 == &a[1]，*(a + 1) == a[1]）。
  • 指针与数组名两大区别（设 int a[10]; int *p = a;）：① a 是（不可 a++、不可赋值），p 是（可 p++、可赋值）；② sizeof(a) 测整个数组大小（int a[10] 为 ，char a[10] 为 ，注：原讲义第 5 页把 char a[10] 笔误印作 40B），sizeof(p) 恒为 。

讲义编程案例：用指针输入 10 人年龄并求平均值、最小值、最大值

C 语言代码
#include <stdio.h>
int main() {
    int age[10], *p = age, i, max, min, sum = 0;
    for (i = 0; i < 10; i++)
        scanf("%d", p + i);             // p + i 等价于 &age[i]
    max = min = *p;                     // 初值取第 1 个元素 age[0]
    for (i = 0; i < 10; i++) {
        int v = *(p + i);               // *(p + i) 等价于 age[i]
        sum += v;
        if (v > max) max = v;
        if (v < min) min = v;
    }
    printf("avg=%.2f, min=%d, max=%d\n", sum / 10.0, min, max);
    return 0;
}
01

必背结论

  • 数组定义时，一个 [] 可以看作一个 *；对 int a[10];，a 是首地址（&a[0]），表达式中可看作 int * 类型。
  • 核心等价公式（必须背）：a + 下标 == &a[下标]；*(a + 下标) == a[下标]（a + 1 指向第 2 个元素 a[1]）。
  • 若 char *p = a;，使用上 p[i] == *(p+i) == *(a+i) == a[i]，但 a 与 p 有两大核心区别：
  • 区别① 可修改性：a 是指针常量（不可 a++，不可 a = ...）；p 是指针变量（可以 p++，可以 p = ...）。
  • 区别② sizeof 大小：sizeof(a) 测量整个数组总字节数（int a[10] 为 40B，char a[10] 为 10B）；sizeof(p) 测量指针本身，永远是 4B（32位）。
02

解题套路

见到 *(p + i) 或 *(a + i) 秒翻译成 p[i] / a[i]；见到 p + i 或 a + i 秒翻译成 &p[i] / &a[i]！

见到 sizeof(数组名) vs sizeof(指针名)：数组名算“元素个数 × 单元素字节数”，指针变量不管指向谁直接答 4（32位）！

易错点

勘误提醒：原讲义第 5 页写 char a[10] = ""; 下方误将 sizeof(a) 印成 40B（那是 int a[10] 的大小）；严谨记忆：char a[10] 的 sizeof(a) = 10 × 1 = 10B，int a[10] 的 sizeof(a) = 10 × 4 = 40B，而 sizeof(p) 无论 char* 还是 int* 均为 4B！

移动指针 p++ 后再取 p[0]，拿到的已经不是原数组 a[0] 而是 p 当前指向的新位置！

七、二维数组与指针：8 大必背等价公式（还原讲义第 1 页 & 第 5 页）

指针表达式等价下标 / 地址写法含义与层级（行指针 → 列指针 → 元素值）
a第 0 行首地址（行指针）
a + i第 i 行地址（行指针，+1 跨一整行）
*(a + i) / 第 i 行第 0 列元素地址（降维成列指针）
*(a + i) + j / a[i] + j第 i 行第 j 列元素地址（列指针）
*(*(a + i) + j)第 i 行第 j 列元素的值（脱两层 *）
**a第 0 行第 0 列元素的值
*a + j第 0 行第 j 列元素地址
*(*a + j)第 0 行第 j 列元素的值
  • int a[10][20] = {0}; 类型分层：a 的类型是 （指向第一行，a + 1 跳过即 &a[1]）；a[0] 是 （第 0 行一维数组名）；a[0][0] 是 。

八、为什么有指针：函数值传递 vs 指针传递终极对照

C 语言代码
// 【值传递】改不了实参
void haha1(int x)  { x++; }       // main: int a=20; haha1(a);  → a 仍为 20

// 【指针传递】必须传 &a 且内部 (*x)++（括号不可省！）
void haha2(int *x) { (*x)++; }    // main: int a=20; haha2(&a); → a 变为 21
01

必背结论

  • 二维数组 int a[10][20]; 中：a[0][0] 是 int 类型，a[0] 是 int[20]（第 0 行数组名 / 可看作 int*），a 是 int[10][20]（指向整行 / 行指针，+1 跳过一整行 20×4=80B）。
  • 二维数组 8 大必背等价公式（①~④）：a == &a[0]；a + i == &a[i]；*(a + i) == a[i] == &a[i][0]；*(a + i) + j == a[i] + j == &a[i][j]。
  • 二维数组 8 大必背等价公式（⑤~⑧）：*(*(a + i) + j) == a[i][j]；**a == a[0][0]；*(*a + j) == a[0][j]；*a + j == &a[0][j]。
  • 为什么有指针（修改实参）：值传递只改形参副本；指针传递把 &a 传给 int *x，函数内用 (*x)++ 才能真正修改实参 a（注意 (*x)++ 括号绝不能省！）。
02

解题套路

二维指针表达式翻译“两步法”：① 先把最内层 *(a + i) 直接改写成 a[i]（若只有 *a 改写成 a[0]）；② 再把外层 *(a[i] + j) 改写成 a[i][j]，不加外层 * 的 a[i] + j 就是 &a[i][j]！

做函数修改实参题：检查是否传了 &a、形参是否是 int *x、修改语句是否写对了 (*x)++（带括号！）而非 *x++。

03

易错点

混淆 a + 1 和 *a + 1：a + 1 是 &a[1]（跳过一整行，行指针）；*a + 1 是 &a[0][1]（只跳过第 0 行的 1 个元素，列指针）！

在函数内写 *x++ 想让实参自增 1：大错！++ 和 * 同级右结合，*x++ 先让指针 x 指向下一个垃圾地址，必须写 (*x)++！

记死两个 * 才取到二维数组元素值：只脱一层 *（如 *(a+1)+3）得到的还是地址 &a[1][3]，不是元素值！

漏看最外层有没有 * 而误选 A（地址）。

题目

对于二维数组 int a[3][4]; 下列关于指针表达式含义的说法中，错误的是（ ）。

  • A. a + 1 表示第 1 行的地址 &a[1]
  • B. *a + 1 表示第 0 行第 1 列元素的地址 &a[0][1]
  • C. **a 表示元素 a[0][0] 的值
  • D. *(a + 1) 表示元素 a[1][0] 的值
查看逐步解答

第一眼判断

  1. A 对：a 指向第 0 行，a + 1 跳过一整行即 &a[1]。
