整理

属性作用备注
bgcolor设置页面背景色可与背景图同时设置
background设置页面背景图像显示背景图像
link未访问链接颜色默认蓝色
alink正在点击时的链接颜色默认红色
vlink已访问链接颜色默认紫色
text非链接文字默认颜色
topmargin页面上边距单位：像素 px
leftmargin页面左边距单位：像素 px

记忆：link / alink / vlink 管三种链接状态；topmargin、leftmargin 用 px。

讲解

  • 直观意思： bgcolor 给整个网页铺底色，background 给整个网页铺背景图。手写批注：bgcolor 旁为“同时设置背景【看不清】和图像”，background 旁为“显示背景图像”。
  • 为什么： 在绘制层级上，背景图像覆盖在纯背景颜色之上。同时设置两者原本有一个实用目的：当背景图片加载失败、路径错误，或者图片有透明区域时，底下的 bgcolor 颜色就会露出来兜底。
  • 直观意思： 这四个属性管网页里“字的颜色”：
    • text 管普通文字（非链接文字）的颜色；
    • link / alink / vlink 专管超链接文字在三种不同状态下的颜色：没点过是 link（默认蓝）、鼠标按住那一瞬间是 alink（默认红）、点过访问完回来是 vlink（默认紫）。 英文词根记忆法：link = link（未访问链接），alink = active link（活动/点击瞬间链接），vlink = visited link（已访问链接）。
  • 为什么： 超链接需要给用户明确的交互反馈：哪些入口我还没看过（蓝）、我现在确实点中了（红）、哪些页面我已经浏览过不用重复点（紫）。把普通文字 text 和超链接颜色分开控制，也是为了保证链接在正文中足够醒目。
  • 为什么： 早期还没有完善普及 CSS，只能把背景、颜色、边距直接塞进 <body> 标签属性里；后来为了实现“结构与表现分离”（第 1 章三层结构原则），HTML5 废弃了这些表现型属性，全部交给了 CSS 的 background、链接伪类（:link、:visited、:hover、:active）和 margin 来控制。

自测要点解答

  1. 按功能拆成 3 组记（共 8 个属性）：
    • 背景组（2 个）：
      • bgcolor：页面背景颜色
      • background：页面背景图像
      • 手写批注：bgcolor 旁为“同时设置背景【看不清】和图像”，background 旁为“显示背景图像”。
    • 颜色组（4 个）：
      • text：非链接文本的默认颜色
      • link：未访问链接颜色 → 默认蓝色
      • alink：活动链接（点击瞬间）颜色 → 默认红色
      • vlink：已访问链接颜色 → 默认紫色
    • 边距组（2 个）：
      • topmargin：页面上页边距 → 单位：像素 px
      • leftmargin：页面左页边距 → 单位：像素 px
  2. 盯紧考题高频陷阱：
    • 问“背景图片”选 background，问“背景颜色”选 bgcolor，别看反！
    • 记口诀：未蓝、点红、已紫（link 蓝、alink 红、vlink 紫）。
    • 问“现代开发用什么替代”：CSS 的 background、:link/:visited/:hover/:active、margin。
