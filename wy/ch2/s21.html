2.1 HTML 简介

HTML（Hyper Text Markup Language，超文本标记语言）是一种用来描述网页结构和内容的标记语言。代码由标记（也称为标签，或者元素）和属性构成。

超【看不清】　标记　语言

HTML 标签就像是包裹着文字、图片或其他元素的“盒子”，它告诉浏览器如何显示内容。标签通常用尖括号 < > 包围，主要分为两种形式：

整理

HTML = Hyper Text Markup Language = 超文本标记语言，用来描述网页的结构和内容。

HTML 代码由标记（标签 / 元素）和属性组成。标签像「盒子」包住文字、图片等，告诉浏览器如何显示。标签写在尖括号 < > 里。

自测要点

  1. 1HTML 全称与中文名：超文本标记语言

1、双标签（成对出现）

1、双标签（成对出现）：由一个“开始标签”和一个“结束标签”组成，中间包裹着具体内容。例如段落标签 <p>这是一个段落</p>，浏览器看到它就知道要把中间的文字当作一个独立的段落来展示。

2. 单标签（自闭合标签）

2. 单标签（自闭合标签）：只有一个标签，不需要包裹内容，因为它本身就是一个独立的元素。例如插入图片的标签 <img/> 或换行标签 <br/>。

整理

双标签 vs 单标签

类型说明示例
双标签开始标签 + 结束标签，中间包内容<p>这是一个段落</p>
单标签只有一个标签，无包裹内容<img>、<br/>

自测要点

  1. 2双标签 vs 单标签

HTML 属性（无编号段）

HTML 属性是用来补充说明标签的样式或附加功能的。属性总是以“属性="属性值"”的形式出现（例如 name="value"），并且写在标签的开始标签内部。举个例子，在图片标签中：

<img src="photo.jpg" alt="一张风景照" width="300"/>，src，alt，width 都是属性，具体含义后面章节详细介绍。

整理

属性

给标签提供额外信息或样式，写法：name="value"，写在开始标签内。

<img src="photo.jpg" alt="一张风景照" width="300"/>

src、alt、width 都是属性。

HTML 简介

HTML（Hyper Text Markup Language）是超文本标记语言，用来描述网页的结构和内容。辽宁专升本网页设计科目，多数题目从「标签含义、属性写法、文档结构」切入。

它做什么

  • 用标签把文字、图片、链接等「框」起来，告诉浏览器这是标题、段落还是列表。
  • 本身不负责华丽外观（那是 CSS），也不负责复杂交互（那是 JavaScript）。

和三层结构的关系

回顾第1章：结构层 HTML、样式层 CSS、行为层 JavaScript。学 HTML 时先把骨架写对，再谈美化和交互。

最小认识

<p>这是一个段落</p>

<p> 是开始标签，</p> 是结束标签，中间是内容。

试一试

HTML 属性

属性写在开始标签里，格式 名字="值"，给元素补充信息。

  • id：页面内唯一标识
  • class：样式分类名（可重复）
  • title：鼠标悬停提示
  • style：行内样式（能用外链 CSS 时少用）
试一试

HTML 元素

元素 ≈ 开始标签 + 内容 + 结束标签。没有内容的叫空元素（单标签），如 <br>、<img>。
