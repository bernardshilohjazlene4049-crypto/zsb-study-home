2.1 HTML 简介

HTML（Hyper Text Markup Language，超文本标记语言）是一种用来描述网页结构和内容的标记语言。代码由标记（也称为标签，或者元素）和属性构成。

超【看不清】　标记　语言

HTML 标签就像是包裹着文字、图片或其他元素的“盒子”，它告诉浏览器如何显示内容。标签通常用尖括号 < > 包围，主要分为两种形式：

整理

HTML = Hyper Text Markup Language = 超文本标记语言，用来描述网页的结构和内容。

HTML 代码由标记（标签 / 元素）和属性组成。标签像「盒子」包住文字、图片等，告诉浏览器如何显示。标签写在尖括号 < > 里。

讲解

  • 直观意思： HTML 就是给网页搭“骨架”的说明书。你写一段普通文字，浏览器不知道它是标题还是正文；你用尖括号 < > 这种“盒子”把它包起来，浏览器就知道“哦，这是标题、这是段落、这是图片”。整个 HTML 代码拆到最底，就是两大件：标签（盒子本身）和属性（贴在盒子上的参数标签）。 所谓“超文本”，直观上就是超越纯文字的文本，能包含图片、超链接等跳转与多媒体内容。
  • 为什么： 浏览器本身只是一个按规则渲染画面的程序，看不懂人类自然语言的排版意图。必须有一套统一、规范的“标记”语法，把内容是什么（HTML 结构层）、长得好看不好看（CSS 样式层）、点它怎么动（JavaScript 行为层）分开管理。这样浏览器才能准确解析，开发者也方便分工维护。

自测要点解答

  1. 拆解缩写字母：
    • H = Hyper（超）
    • T = Text（文本）
    • M = Markup（标记）
    • L = Language（语言）
  2. 关联核心职责：HTML 用来描述网页的结构和内容，代码由标记（标签 / 元素）和属性构成；样式交给 CSS，交互交给 JavaScript。

自测要点

  1. 1HTML 全称与中文名：超文本标记语言

1、双标签（成对出现）

1、双标签（成对出现）：由一个“开始标签”和一个“结束标签”组成，中间包裹着具体内容。例如段落标签 <p>这是一个段落</p>，浏览器看到它就知道要把中间的文字当作一个独立的段落来展示。

讲解

  • 直观意思：
    • 双标签像有盖有底的收纳箱：有开头 <p>，有结尾 </p>（多一个斜杠 /），中间装着你要展示的文字或其他标签。
    • 单标签像一枚独立印章：盖下去就生效，里面装不下东西，比如“在这里换行 <br/>”或者“在这里放一张图 <img/>”。
  • 为什么： 段落、标题、分区这类元素需要明确“从哪儿开始、到哪儿结束”，否则浏览器不知道后面哪些字还属于这一段，所以必须成对出现；而换行、图片本身不包裹文字内容（图片显示哪张图是由属性指定的），给它配结束标签没有意义，因此设计成单标签（空元素）。 在 HTML5 规范中，单标签末尾的斜杠 / 可以省略，写成 <br>、<img> 和写成 <br/>、<img/> 都能被浏览器正常识别。

2. 单标签（自闭合标签）

2. 单标签（自闭合标签）：只有一个标签，不需要包裹内容，因为它本身就是一个独立的元素。例如插入图片的标签 <img/> 或换行标签 <br/>。

整理

双标签 vs 单标签

类型说明示例
双标签开始标签 + 结束标签，中间包内容<p>这是一个段落</p>
单标签只有一个标签，无包裹内容<img>、<br/>

讲解

自测要点解答

  1. 看有没有“结束标签”：
    • 双标签（成对出现）：由“开始标签” + “结束标签（带 /）”组成，中间包裹具体内容。
    • 单标签（自闭合标签 / 空元素）：只有一个标签，不需要包裹内容，自身就是一个独立元素。
  2. 两类各举代表：
    • 双标签例子：段落标签 <p>这是一个段落</p>（以及结构里的 <html>、<head>、<title>、<body>、<div>）。
    • 单标签例子：图片标签 <img/>（或 <img>）、换行标签 <br/>（或 <br>）（以及 <meta>、<input>）。
  3. 结合属性书写位置做判断：无论双标签还是单标签，属性都写在开始标签内部，格式为 属性="属性值"，例如 <img src="photo.jpg" alt="一张风景照" width="300"/>。

HTML 属性

HTML 属性是用来补充说明标签的样式或附加功能的。属性总是以“属性="属性值"”的形式出现（例如 name="value"），并且写在标签的开始标签内部。举个例子，在图片标签中：

<img src="photo.jpg" alt="一张风景照" width="300"/>，src，alt，width 都是属性，具体含义后面章节详细介绍。

整理

属性

给标签提供额外信息或样式，写法：name="value"，写在开始标签内。

<img src="photo.jpg" alt="一张风景照" width="300"/>

src、alt、width 都是属性。

讲解

  • 直观意思： 标签只决定了“这是什么东西”，属性决定了“这个东西的具体参数”。就像你喊“放一张图片（<img>）”，浏览器会反问：图片文件在哪（src）？图加载不出来显示什么字（alt）？多宽（width）？这些都以 属性名="属性值" 的键值对写在开始标签里面。
  • 为什么： 如果每种宽度、每张图片都单独造一个新标签，标签数量会爆炸。把共性抽象成标签、把个性抽离成属性，就能用有限的标签组合出无穷的页面效果。属性必须写在开始标签里（不能写在结束标签里），是因为浏览器是从上往下流式解析代码的，遇到开始标签就要立刻知道怎么初始化和渲染这个元素。

延伸

HTML 简介

HTML（Hyper Text Markup Language）是超文本标记语言，用来描述网页的结构和内容。辽宁专升本网页设计科目，多数题目从「标签含义、属性写法、文档结构」切入。

它做什么

  • 用标签把文字、图片、链接等「框」起来，告诉浏览器这是标题、段落还是列表。
  • 本身不负责华丽外观（那是 CSS），也不负责复杂交互（那是 JavaScript）。

和三层结构的关系

最小认识

<p>这是一个段落</p>

<p> 是开始标签，</p> 是结束标签，中间是内容。

试一试

讲解

实操题解答

  1. 定位控制文字颜色的属性：在第一个 <p> 的开始标签中，有 4 个属性：id（唯一标识）、class（样式分类名）、title（鼠标悬停提示）、style（行内样式）。决定颜色的是 style 里的 color:#245444;。
  2. 修改属性值：将 color:#245444 改为 color:orange（或十六进制橙色如 #ff8800）。
  3. 核对英文标点与引号：确保 style="..." 保持英文双引号，两条样式之间保留英文分号 ;：
<p id="p1" class="note" title="悬停看看" style="color:orange;font-weight:700">
  带属性的段落
</p>

HTML 属性

属性写在开始标签里，格式 名字="值"，给元素补充信息。

  • id：页面内唯一标识
  • class：样式分类名（可重复）
  • title：鼠标悬停提示
  • style：行内样式（能用外链 CSS 时少用）

HTML 元素

元素 ≈ 开始标签 + 内容 + 结束标签。没有内容的叫空元素（单标签），如 <br>、<img>。
