2.2 HTML5 文档结构

HTML 语言目前所用的版本是 HTML5,该版本文档结构由声明、根标签、头部标签和主体标签四部分组成：

整理

最小完整示例

整理

最小完整示例

<!doctype html>
<html>
  <head>
    <meta charset="utf-8">
    <title>myweb</title>
  </head>
  <body>
    中国，你好！
  </body>
</html>

浏览器标签栏显示 myweb，主窗口显示「中国，你好！」。

2. 结构说明

2. 结构说明：

●<!doctype html>：文档类型声明，告诉浏览器当前是 HTML5 标准。

●<html>：根标签，包裹整个 HTML 文档。

●<head>：文件头标签，存放网页的基础配置信息（如编码、标题、元数据）。

●<meta>：元数据标签。

utf-8 万国码 设置网页的编码格式 GB2312

●<title>：网页标题标签，显示在浏览器标签栏。

唯一 必须在<head></head>里

●<body>：文件体标签，所有页面可见内容都写在这里，会在浏览器主窗口中显示。

浏览器运行效果如图所示：

结构说明

标签作用
<!doctype html>文档类型声明，告诉浏览器当前是 HTML5 标准
<html>根标签，包裹整个 HTML 文档
<head>文件头，存放基础配置（编码、标题、元数据）
<meta>元数据标签（如设置编码 utf-8 / GB2312）
<title>网页标题，显示在浏览器标签栏；★ 唯一必须写在 <head></head> 里的内容
<body>文件体，所有页面可见内容写在这里，显示在浏览器主窗口

自测要点

  1. 4<title> 是唯一必须在 <head> 里的内容

HTML 基础

一份合格网页至少包含：文档声明、根元素、头部、主体。第2章已讲四部分结构，这里补上「标题 / 段落 / 链接 / 图片」四件套实例。

<!doctype html>
<html lang="zh-CN">
<head>
  <meta charset="utf-8">
  <title>页面标题</title>
</head>
<body>
  <h1>一级标题</h1>
  <p>段落文字。</p>
  <a href="https://example.com">链接文字</a>
  <img src="pic.jpg" alt="说明文字">
</body>
</html>

HTML5 简介

HTML5 是 HTML 的当代标准。声明写作 <!doctype html>（第2章已练）。相对旧版，它补强了语义标签、音视频、画布、本地存储等。

  • 更清晰的页面分区标签
  • 原生 audio / video，减少插件
  • 表单控件类型更丰富
