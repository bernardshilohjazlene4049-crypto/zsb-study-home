SVG 概述

重点

SVG（可缩放矢量图形）用 XML 描述形状，放大不糊。可内嵌在 HTML 中；适合图标、简单图表。对比 Canvas：SVG 是 DOM 节点，Canvas 是像素位图。

试一试

考试提醒

  • SVG 适合图标；复杂游戏画面更常用 Canvas。
  • 基本形状：rect circle line path text。
