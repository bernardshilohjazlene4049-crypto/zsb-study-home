浏览器支持

不同浏览器对 HTML5 新特性支持程度不同。现代 Chrome/Edge/Firefox/Safari 对语义标签、音视频、canvas、本地存储支持良好；老旧 IE 需谨慎。考试了解「特性检测 / 优雅降级」即可。

试一试

考试提醒

  • 不要死记版本表；理解「检测是否支持再使用」。
  • 语义标签在旧浏览器可能当未知元素，可用 CSS display:block 兜底（了解）。
