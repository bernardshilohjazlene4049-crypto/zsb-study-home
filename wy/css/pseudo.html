网页设计 / CSS / 伪类

伪类

已上线★常考

伪类选「状态」：:hover、:focus、:first-child、:nth-child、:checked 等。伪元素选「片段」：::before、::after、::first-line。

试一试

改代码后点「运行」看预览。

考试提醒

  • 伪类一个冒号，伪元素现代写法两个冒号。
  • ::before/::after 必须有 content 才显示。
