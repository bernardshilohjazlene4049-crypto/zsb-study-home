1.1 网页相关概念

1. 网站

1.1 网页相关概念

1. 网站：网站(Web Site)是一个存放在网络服务器上的相关信息的集合体。它包含一个或多个网页，这些网页以一定的方式链接在一起，成为一个整体，用来描述一组完整的信息或达到某种期望的宣传效果。

整理

1. 网站（Web Site）

部署在网络服务器上的一组信息集合。它包含一个或多个网页，这些网页按某种方式链接在一起，形成一个整体，用以描述信息或达到宣传效果。

2. 网页

2. 网页：网页(Web pages)是网站的组成部分，由文字、图形、图像、音频、视频、动画、脚本程序、超链接等网页元素组成。通过浏览器访问。每个网页都有唯一的 URL 地址，用于定位和访问。

整理

2. 网页（Web pages）

网站的组成部分，由文字、图形、图像、声音、视频、动画、脚本、超链接等组成。每个网页都有一个唯一的 URL 地址，用于定位和访问。

3. URL

3. URL(Uniform Resource Locator，统一资源定位器，即网址)：用于描述 Internet 上资源位置和访问方式。

URL 组成：协议类型://服务器地址（端口号）/路径/文件名

顶级域名：com（公司）、net（网络机构）、org（组织机构）、edu（教育）、gov（政府部门）、mil（军事机构）和 ac（科研机构）

6. 互联网（Internet）

6. 互联网（Internet）：又称国际网络或因特网，是由全球范围内众多计算机网络通过通用协议（如 TCP/IP）相互连接而成的庞大网络基础设施。它并非单一网络，而是“网络的网络”，将分散的局域网、广域网等整合为一个逻辑上统一的全球性系统。

整理

6. Internet（互联网，又称国际网络或因特网）

由世界各地众多计算机网络通过共同协议（如 TCP/IP）互联而成的巨大网络基础设施。它不是单一网络，而是「网络的网络」。

8. 浏览器/服务器交互过程

8. 浏览器/服务器交互过程：

(1)浏览器从网址中获取输入的域名；

(2)浏览器向 DNS 请求解析域名对应的 IP 地址；

(3)浏览器与该服务器建立 TCP 连接；

(4)浏览器发出 HTTP 请求，请求网页；

(5)服务器通过 HTTP 响应把网页发送给浏览器；

(6)TCP 连接释放；

(7)浏览器将首页文件进行解析，并将 Web 页显示给用户。

整理

8. 浏览器与服务器的交互过程

  1. 浏览器从输入的 URL 中取得域名
  2. 浏览器请求 DNS 解析该域名对应的 IP 地址
  3. 浏览器与服务器建立 TCP 连接
  4. 浏览器发出 HTTP 请求，请求网页
  5. 服务器通过 HTTP 响应把网页发送给浏览器
  6. TCP 连接释放
  7. 浏览器解析首页文件，并将 Web 页面显示给用户

自测要点

10. 静态网页和动态网页：

静态网页：内容固定，无数据库交互，常见扩展名有.htm 或.html；

动态网页：内容不固定，按需生成，有数据库交互，常见扩展名为：.asp、.php、.jsp
