1.3 网页的层次结构

1. 结构层：网页的骨架，HTML 是网页内容的载体，内容就是网页制作者放在页面上想要让用户浏览的信息，可以包含文字、图像、视频等。

2. 样式层：CSS 样式是表现。就像网页的外衣，比如，标题字体、颜色变化，或为标题加入背景图片、边框等，所有这些用来改变内容外观的东西称之为表现

层

3. 行为层：Java Script 是用来实现网页上的特效效果。如：鼠标滑过弹出下拉菜单、鼠标滑过表格的背景颜色改变，或者焦点新闻（新闻图片）的轮换。可以这么理解，有交互的一般都是用 Java Script 来实现的。

实现网页动态性和交互性

整理

1. 结构层

网页的骨架。HTML 是网页内容的载体；内容是制作者放在页面上想让用户浏览的信息，可包含文字、图像、视频等。

2. 样式层

CSS 样式是表现，像网页的外衣。例如标题字体、颜色变化，或为标题加入背景图片、边框等——凡用来改变内容外观的，都叫表现。

3. 行为层

JavaScript 用来实现网页上的特效效果，例如：

  • 鼠标滑过弹出下拉菜单
  • 鼠标滑过表格背景颜色改变
  • 焦点新闻（新闻图片）轮换

有交互的一般都用 JavaScript 实现 → 实现网页动态性和交互性。
