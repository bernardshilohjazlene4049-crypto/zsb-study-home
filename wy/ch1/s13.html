1.3 网页的层次结构

1. 结构层：网页的骨架，HTML 是网页内容的载体，内容就是网页制作者放在页面上想要让用户浏览的信息，可以包含文字、图像、视频等。

整理

1. 结构层

网页的骨架。HTML 是网页内容的载体；内容是制作者放在页面上想让用户浏览的信息，可包含文字、图像、视频等。

讲解

  • 直观意思：结构层就是盖房子的“钢筋骨架”或人体的“骨骼”，由 HTML 负责把要展示的文字、图片、视频等核心内容搭好框架摆上去。
  • 为什么：无论外观多华丽、特效多炫酷，用户看网页的根本目的是获取信息，必须先由 HTML 把内容和语义骨架立起来。

可视化讲解

2. 样式层

2. 样式层：CSS 样式是表现。就像网页的外衣，比如，标题字体、颜色变化，或为标题加入背景图片、边框等，所有这些用来改变内容外观的东西称之为表现

层

整理

2. 样式层

CSS 样式是表现，像网页的外衣。例如标题字体、颜色变化，或为标题加入背景图片、边框等——凡用来改变内容外观的，都叫表现。

讲解

  • 直观意思：样式层（也叫表现层）就是给骨架穿上的“衣服和妆容”，由 CSS 控制字号、颜色、背景图、边框、排版等一切视觉外观。
  • 为什么：把外观（CSS）从内容（HTML）里拆出来，可以实现“换肤不换骨”——改一份样式表就能统一改变整个网站的外观，大幅降低维护成本。

3. 行为层

3. 行为层：Java Script 是用来实现网页上的特效效果。如：鼠标滑过弹出下拉菜单、鼠标滑过表格的背景颜色改变，或者焦点新闻（新闻图片）的轮换。可以这么理解，有交互的一般都是用 Java Script 来实现的。

实现网页动态性和交互性

整理

3. 行为层

JavaScript 用来实现网页上的特效效果，例如：

  • 鼠标滑过弹出下拉菜单
  • 鼠标滑过表格背景颜色改变
  • 焦点新闻（新闻图片）轮换

有交互的一般都用 JavaScript 实现 → 实现网页动态性和交互性。

讲解

  • 直观意思：行为层就是让穿上衣服的骨架“动起来、会回应人”，由 JavaScript 负责处理各种交互与特效（如悬停菜单、变色、图片轮播）。
  • 为什么：光有 HTML 和 CSS 的页面主要是静态展示，用户点按、滑动、切换内容等动态交互逻辑需要脚本语言（JavaScript）在浏览器端响应事件并执行。

自测要点解答

  1. 建立“层级 — 技术 — 比喻 — 作用”四列精准映射：
    • 结构层 ↔ HTML ↔ 骨架 ↔ 网页内容的载体（文字、图像、视频等）；
    • 样式层（表现层） ↔ CSS ↔ 外衣 ↔ 改变内容外观（字体、颜色、背景图、边框等）；
    • 行为层 ↔ JavaScript ↔ 动作/交互 ↔ 特效效果，实现网页动态性和交互性（下拉菜单、滑过变色、焦点图轮换等）。
  2. 做情景题快速定位法：
    • 题目问“往页面放一段文字或视频” → 选结构层 / HTML；
    • 题目问“改标题颜色、加边框、设背景图” → 选样式层（表现）/ CSS；
    • 题目问“鼠标滑过弹出菜单、焦点新闻图片轮换、实现交互” → 选行为层 / JavaScript。

自测要点

  1. 8三层结构：HTML（结构）+ CSS（样式/表现）+ JavaScript（行为/交互）
