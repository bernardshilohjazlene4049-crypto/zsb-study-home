网页制作开发工具
记事本、HBuilder、vscode

整理

记事本、HBuilder、VS Code

讲解

  • 直观意思：写网页代码不需要特别神秘的软件，最基础的 Windows 自带“记事本”就能写，专业写代码常用 HBuilder 或 VS Code。
  • 为什么：HTML/CSS/JS 本质上都是纯文本代码文件，所以任何纯文本编辑器（哪怕记事本）都能编写；而 HBuilder 和 VS Code 提供语法高亮、代码补全、实时预览等能力，能大幅提高开发效率。
