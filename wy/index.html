1.1 网页相关概念

1. 网站（Web Site）

部署在网络服务器上的一组信息集合。它包含一个或多个网页，这些网页按某种方式链接在一起，形成一个整体，用以描述信息或达到宣传效果。

2. 网页（Web pages）

网站的组成部分，由文字、图形、图像、声音、视频、动画、脚本、超链接等组成。每个网页都有一个唯一的 URL 地址，用于定位和访问。

3. URL（Uniform Resource Locator，统一资源定位器，即网址）

用来描述 Internet 上资源的位置和访问方法。

组成格式：

协议类型://服务器地址(端口号)/路径/文件名

常见顶级域名：

域名含义
com公司企业
net网络组织
org组织机构
edu教育机构
gov政府部门
mil军事组织
ac科研机构

4. DNS（Domain Name System，域名系统）

管理、安排域名的分布式数据库系统，实现域名与 IP 地址的映射。

要点：

  • 一个域名只能映射到一个 IP 地址
  • 一个 IP 地址可以映射到多个域名

5. 首页（Home page）

网站的第一个网页，反映站的主题。常见首页文件名：index.html、default.html。

6. Internet（互联网，又称国际网络或因特网）

由世界各地众多计算机网络通过共同协议（如 TCP/IP）互联而成的巨大网络基础设施。它不是单一网络，而是「网络的网络」。

7. 网站、网页与 Internet 的关系

  • Internet：全球网络基础设施
  • 网站：部署在 Internet 上的信息集合
  • 网页：构成网站的基本单元

补充：WWW 服务是 Internet 上最广泛的服务。

8. 浏览器与服务器的交互过程

  1. 浏览器从输入的 URL 中取得域名
  2. 浏览器请求 DNS 解析该域名对应的 IP 地址
  3. 浏览器与服务器建立 TCP 连接
  4. 浏览器发出 HTTP 请求，请求网页
  5. 服务器通过 HTTP 响应把网页发送给浏览器
  6. TCP 连接释放
  7. 浏览器解析首页文件，并将 Web 页面显示给用户

9. HTTP 协议

HTTP（Hypertext Transfer Protocol，超文本传输协议）详细规定了浏览器和万维网服务器之间互相通信的规则。

10. 静态网页和动态网页

类型特点常见扩展名
静态网页内容固定，无数据库交互.htm、.html
动态网页内容不固定，按需生成，有数据库交互.asp、.php、.jsp、.aspx（含 ASP.Net）

1.2 网页设计基本流程

  1. 分析：认识网页将要服务的目标群体（群体特征、可能需求等），确定网页信息内容及其功能设计。
  2. 设计：关键环节，影响用户对网页的接受和利用程度。包括：收集素材、确定内容结构与链接方式、网页模型可视化设计。
  3. 制作：选择熟悉的网页制作工具，把文字、图片、动画、声音、视频、程序等素材按设计要求合成。
  4. 测试：全面检测内容科学性、版面合理性、超链接正确性，并对内容做适当增减。
  5. 发布：把网页发布到网上，让更多浏览者访问；不发布就失去制作意义。

记忆口诀：分析 → 设计 → 制作 → 测试 → 发布

1.3 网页的层次结构

1. 结构层

网页的骨架。HTML 是网页内容的载体；内容是制作者放在页面上想让用户浏览的信息，可包含文字、图像、视频等。

2. 样式层

CSS 样式是表现，像网页的外衣。例如标题字体、颜色变化，或为标题加入背景图片、边框等——凡用来改变内容外观的，都叫表现。

3. 行为层

JavaScript 用来实现网页上的特效效果，例如：

  • 鼠标滑过弹出下拉菜单
  • 鼠标滑过表格背景颜色改变
  • 焦点新闻（新闻图片）轮换

有交互的一般都用 JavaScript 实现 → 实现网页动态性和交互性。

2.1 HTML 简介

HTML = Hyper Text Markup Language = 超文本标记语言，用来描述网页的结构和内容。

HTML 代码由标记（标签 / 元素）和属性组成。标签像「盒子」包住文字、图片等，告诉浏览器如何显示。标签写在尖括号 < > 里。

双标签 vs 单标签

类型说明示例
双标签开始标签 + 结束标签，中间包内容<p>这是一个段落</p>
单标签只有一个标签，无包裹内容<img>、<br/>

属性

给标签提供额外信息或样式，写法：name="value"，写在开始标签内。

<img src="photo.jpg" alt="一张风景照" width="300"/>

src、alt、width 都是属性。

2.2 HTML5 文档结构

当前主流版本是 HTML5。文档结构四部分：声明、根标签、头标签、体标签。

最小完整示例

<!doctype html>
<html>
  <head>
    <meta charset="utf-8">
    <title>myweb</title>
  </head>
  <body>
    中国，你好！
  </body>
</html>

浏览器标签栏显示 myweb，主窗口显示「中国，你好！」。

结构说明

标签作用
<!doctype html>文档类型声明，告诉浏览器当前是 HTML5 标准
<html>根标签，包裹整个 HTML 文档
<head>文件头，存放基础配置（编码、标题、元数据）
<meta>元数据标签（如设置编码 utf-8 / GB2312）
<title>网页标题，显示在浏览器标签栏；★ 唯一必须写在 <head></head> 里的内容
<body>文件体，所有页面可见内容写在这里，显示在浏览器主窗口

2.2 HTML5 编写注意事项（必记）

  1. 标记可以嵌套，但不能交叉嵌套
    正确：<div><p>这是一段嵌套的文本</p></div>
    错误：<div><p>交叉嵌套的文本</div></p>
  2. 不区分大小写，建议用小写
  3. 标记中可以放各种属性，属性值建议用双引号包裹
  4. 缩进书写，便于阅读
  5. 标点符号全部使用英文输入法输入（★常考）
  6. 允许部分属性值省略（布尔属性）：如 <input type="checkbox" checked>，不必写成 checked="checked"
  7. 注释：<!--注释内容-->，注释不会在浏览器中显示，用于代码说明。

2.3 <meta> 标签详解

<meta> 用来定义网页的元数据（描述性信息），不直接显示在页面上，但会被浏览器和搜索引擎识别。

  1. 关键字（供搜索引擎抓取）
    <meta name="keywords" content="HTML,前端开发,学习教程">
  2. 网页描述（搜索结果中会显示）
    <meta name="description" content="这是 HTML 基础入门教程，适合新手学习">
  3. 作者
    <meta name="author" content="马斯克">
  4. 字符集（防止乱码）
    <meta charset="utf-8">
    笔记补充：也可用 GB2312（中文简体）。
  5. 自动刷新 / 跳转
    <meta http-equiv="refresh" content="10;url=https://www.example.com">
    • 10：秒数
    • url：跳转目标
    • 也可表示每隔 10 秒刷新当前页面（不写 url 时）

2.4 <body> 标签详解

属性作用备注
bgcolor设置页面背景色可与背景图同时设置
background设置页面背景图像显示背景图像
link未访问链接颜色默认蓝色
alink正在点击时的链接颜色默认红色
vlink已访问链接颜色默认紫色
text非链接文字默认颜色
topmargin页面上边距单位：像素 px
leftmargin页面左边距单位：像素 px

记忆：link / alink / vlink 管三种链接状态；topmargin、leftmargin 用 px。
