1.1 网页相关概念

1. 网站（Web Site）

部署在网络服务器上的一组信息集合。它包含一个或多个网页，这些网页按某种方式链接在一起，形成一个整体，用以描述信息或达到宣传效果。

2. 网页（Web pages）

网站的组成部分，由文字、图形、图像、声音、视频、动画、脚本、超链接等组成。每个网页都有一个唯一的 URL 地址，用于定位和访问。

3. URL（Uniform Resource Locator，统一资源定位器，即网址）

用来描述 Internet 上资源的位置和访问方法。

组成格式：

协议类型://服务器地址(端口号)/路径/文件名

4. DNS（Domain Name System，域名系统）

管理、安排域名的分布式数据库系统，实现域名与 IP 地址的映射。

要点：

  • 一个域名只能映射到一个 IP 地址
  • 一个 IP 地址可以映射到多个域名

5. 首页（Home page）

网站的第一个网页，反映站的主题。常见首页文件名：index.html、default.html。

6. Internet（互联网，又称国际网络或因特网）

由世界各地众多计算机网络通过共同协议（如 TCP/IP）互联而成的巨大网络基础设施。它不是单一网络，而是「网络的网络」。

7. 网站、网页与 Internet 的关系

  • Internet：全球网络基础设施
  • 网站：部署在 Internet 上的信息集合
  • 网页：构成网站的基本单元

补充：WWW 服务是 Internet 上最广泛的服务。

8. 浏览器与服务器的交互过程

  1. 浏览器从输入的 URL 中取得域名
  2. 浏览器请求 DNS 解析该域名对应的 IP 地址
  3. 浏览器与服务器建立 TCP 连接
  4. 浏览器发出 HTTP 请求，请求网页
  5. 服务器通过 HTTP 响应把网页发送给浏览器
  6. TCP 连接释放
  7. 浏览器解析首页文件，并将 Web 页面显示给用户

9. HTTP 协议

HTTP（Hypertext Transfer Protocol，超文本传输协议）详细规定了浏览器和万维网服务器之间互相通信的规则。

1.2 网页设计基本流程

  1. 分析：认识网页将要服务的目标群体（群体特征、可能需求等），确定网页信息内容及其功能设计。
  2. 设计：关键环节，影响用户对网页的接受和利用程度。包括：收集素材、确定内容结构与链接方式、网页模型可视化设计。
  3. 制作：选择熟悉的网页制作工具，把文字、图片、动画、声音、视频、程序等素材按设计要求合成。
  4. 测试：全面检测内容科学性、版面合理性、超链接正确性，并对内容做适当增减。
  5. 发布：把网页发布到网上，让更多浏览者访问；不发布就失去制作意义。

记忆口诀：分析 → 设计 → 制作 → 测试 → 发布

1.3 网页的层次结构

1. 结构层

网页的骨架。HTML 是网页内容的载体；内容是制作者放在页面上想让用户浏览的信息，可包含文字、图像、视频等。

2. 样式层

CSS 样式是表现，像网页的外衣。例如标题字体、颜色变化，或为标题加入背景图片、边框等——凡用来改变内容外观的，都叫表现。

3. 行为层

JavaScript 用来实现网页上的特效效果，例如：

  • 鼠标滑过弹出下拉菜单
  • 鼠标滑过表格背景颜色改变
  • 焦点新闻（新闻图片）轮换

有交互的一般都用 JavaScript 实现 → 实现网页动态性和交互性。
