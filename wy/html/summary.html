HTML 总结

  1. HTML 描述结构；CSS 管外观；JS 管行为。
  2. 文档四件套：doctype、html、head、body。
  3. 标签可嵌套不可交叉；属性 名="值"；英文标点。
  4. 常考：标题、段落、格式化、链接、图片、表格、列表、表单、实体、三种 CSS 引入。
  5. 结合课程讲义第1–2章概念与文档结构一起背。
