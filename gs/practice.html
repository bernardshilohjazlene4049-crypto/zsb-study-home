49 题考点四–七

做极限题的总流程

每道题都先走一遍这个流程。

  1. 先代入：把 x 的趋向值直接代进去。能算出确定的数，那就是答案。
  2. 判断类型：代入后如果得到 0/0、∞/∞、0·∞、∞-∞、1∞，这叫“未定式”，不能直接下结论，要变形。
  3. 按类型选方法：
    • 0/0：因式分解约分、有理化、等价替换、重要极限 sin□/□→1
    • ∞/∞（x→∞ 的分式）：抓大头，看最高次
    • ∞-∞：通分或有理化，化成分式
    • 0·∞：把一个因子挪到分母，变成 0/0 或 ∞/∞
    • 1∞：重要极限 (1+□)(1/□)→e，或者用公式 lim uv = elim (u-1)·v
  4. 分段函数、含 |x|、含 21/x、e1/x：必须分别求左右极限。

常用八个等价（x→0）：sinx、tanx、arcsinx、arctanx、eˣ-1、ln(1+x) 都 ~ x；1-cosx ~ x²/2；(1+x)m-1 ~ mx。补充：secx-1 ~ x²/2，arcsinx-x ~ x³/6，tanx-x ~ x³/3。 等价替换只能换乘除因子，加减中慎用。

考点四 · 第 1 题

函数 f(x) 在点 x₀ 处有定义是极限 limx→x₀ f(x) 存在的______条件。

✍️ 先自己想：独立写出思路和答案，再展开下面的讲解。

第一眼判断

概念题，考“极限和函数值有没有关系”。

分步解答
  1. 记住结论：x→x₀ 的极限只看 x 靠近 x₀ 时 f 的走向，与 f(x₀) 有无定义、取何值无关。
  2. 有定义能推出极限存在吗？不能（例如分段函数左右极限不等，见 4-4）。所以不充分。
  3. 极限存在能推出有定义吗？不能（例如 (x²-1)/(x-1) 在 x=1 没定义，但极限是 2）。所以不必要。
答案

既不充分也不必要（无关条件）。

易错点

容易误以为“有定义”是必要条件。极限根本不看那一点本身。

通用方法

判断“A 是 B 的什么条件”，就分别问 A⇒B？B⇒A？各举一个反例。

考点四 · 第 2 题

limx→x₀⁻ f(x) = limx→x₀⁺ f(x) = A 是 f(x) 在点 x = x₀ 处有定义的______条件。

✍️ 先自己想：独立写出思路和答案，再展开下面的讲解。

第一眼判断

同 4-1，还是“极限与定义无关”。

分步解答
  1. 左右极限相等只说明极限存在，推不出 x₀ 处有定义。
  2. x₀ 处有定义也推不出左右极限存在且相等。
答案

既不充分也不必要（无关条件）。

易错点

别把“极限存在”和“连续”混在一起。连续才要求有定义且极限等于函数值。

通用方法

极限 ↔ 定义：无关；连续 = 有定义 + 极限存在 + 两者相等。

考点四 · 第 3 题

limx→x₀⁻ f(x) 与 limx→x₀⁺ f(x) 存在且相等是 limx→x₀ f(x) 存在的______条件。

✍️ 先自己想：独立写出思路和答案，再展开下面的讲解。

第一眼判断

直接考“极限存在的充要条件”。

分步解答

笔记原话：x→x₀ 极限存在，当且仅当左右极限都存在且相等。“当且仅当”就是充要。

答案

充分必要条件（充要条件）。

易错点

只有左右极限都存在、而且相等，两个条件缺一不可。

通用方法

看到“左右极限”，第一反应就是“左右存在且相等 ⇔ 极限存在”。

考点四 · 第 4 题

函数 f(x) = { x+1, x<0；x², x≥0 } 在 x=0 处（ ）。
A. 有定义且极限存在　B. 有定义且极限不存在　C. 无定义且极限存在　D. 无定义且极限不存在

✍️ 先自己想：独立写出思路和答案，再展开下面的讲解。

第一眼判断

分段函数在分段点，必须分左右两边求极限。

分步解答
  1. 有没有定义：x=0 属于 “x≥0” 这一段，f(0)=0²=0，有定义。
  2. 左极限（x 从左边靠近 0，用 x<0 那段）：limx→0⁻(x+1) = 0+1 = 1。
  3. 右极限（用 x≥0 那段）：limx→0⁺ x² = 0。
  4. 1 ≠ 0，左右极限不相等，所以极限不存在。
答案

B。

易错点

左极限一定要用 x<0 那一段的式子，别用错段。

通用方法

分段点处求极限 = 左段式子求左极限，右段式子求右极限，再比较。

考点四 · 第 6 题

计算 limx→1 (x²+x-2)/(x-1) = ______。

✍️ 先自己想：独立写出思路和答案，再展开下面的讲解。

第一眼判断

代入 x=1：分子 1+1-2=0，分母 0，是 0/0 型；分子分母都是多项式 → 因式分解约分。

分步解答
  1. 分子 x=1 时为 0，说明分子含有因式 (x-1)。十字相乘：x²+x-2 = (x-1)(x+2)。
  2. 约掉 (x-1)（x→1 但 x≠1，所以可以约）：原式 = limx→1(x+2)。
  3. 代入：1+2 = 3。
答案

3。

易错点

因式分解要验算：(x-1)(x+2) 展开 = x²+x-2 ✓。

通用方法

多项式的 0/0 型 → 找出让分母为 0 的公因式，约掉再代入。

考点四 · 第 7 题

极限 limx→1 (√x - 1)/(x - 1) = ______。

✍️ 先自己想：独立写出思路和答案，再展开下面的讲解。

第一眼判断

代入得 0/0，带根号 → 有理化（或把分母拆成平方差）。

分步解答
  1. 把 x-1 看成 (√x)² - 1² = (√x-1)(√x+1)（平方差公式）。
  2. 原式 = lim (√x-1)/[(√x-1)(√x+1)] = lim 1/(√x+1)。
  3. 代入 x=1：1/(1+1) = 1/2。
答案

1/2。

易错点

分子分母同乘 (√x+1) 也可以，结果一样，别忘了分母也要乘。

通用方法

根号的 0/0 型 → 有理化（乘共轭式）或平方差拆分。

考点四 · 第 10 题

已知函数 f(x)=|2x|，则 limx→0 f(x)/x =（ ）。A. 1　B. -1　C. 2　D. 不存在

✍️ 先自己想：独立写出思路和答案，再展开下面的讲解。

第一眼判断

含绝对值，绝对值在 0 两边的去法不同 → 分左右。

分步解答
  1. x>0 时 |2x| = 2x，f(x)/x = 2，右极限 = 2。
  2. x<0 时 |2x| = -2x，f(x)/x = -2，左极限 = -2。

答案

D。

易错点

把 |2x| 直接当 2x 去算，误选 C。

绝对值 → 按正负去绝对值，分左右极限。

考点四 · 第 11 题

limx→∞ (2x-1)⁶ / (x²+1)³ = ______。

✍️ 先自己想：独立写出思路和答案，再展开下面的讲解。

第一眼判断

x→∞ 的分式，∞/∞ 型 → 抓大头，看最高次。

分步解答
  1. 分子 (2x-1)⁶ 展开后最高次项是 (2x)⁶ = 64x⁶，最高次 6。
  2. 分母 (x²+1)³ 最高次项是 (x²)³ = x⁶，最高次 6。
  3. 笔记结论：n=m 时极限 = 最高次系数之比 = 64/1 = 64。
答案

64。

易错点

(2x)⁶ 的系数是 2⁶ = 64，不是 2。

通用方法

x→∞ 有理分式：只看分子分母最高次项（抓大头）。

考点四 · 第 12 题

已知极限 limx→2 (x²-3x+k)/(x-2) 存在，k = ______。

✍️ 先自己想：独立写出思路和答案，再展开下面的讲解。

第一眼判断

分母 → 0 而极限存在，分子也必须 → 0。

分步解答
  1. 为什么分子必须 → 0：如果分子趋于非 0 的数，除以趋于 0 的分母，结果是 ∞，极限不存在。
  2. 令分子在 x=2 时为 0：4 - 6 + k = 0，k = 2。
  3. 验证：(x²-3x+2)/(x-2) = (x-1)(x-2)/(x-2) = x-1 → 1，存在 ✓。
答案

k = 2。

易错点

别忘了验算极限确实存在。

通用方法

“分母→0，极限存在（为有限数）⇒ 分子→0”，用它列方程求参数。

考点四 · 第 13 题

设 limx→a f(x) = ∞，limx→a g(x) = ∞，则下列正确的是（ ）。
A. lim[f(x)+g(x)] = ∞　B. lim[f(x)-g(x)] = ∞　C. lim 1/f(x) = 0　D. lim 1/[f(x)+g(x)] = 0

✍️ 先自己想：独立写出思路和答案，再展开下面的讲解。

第一眼判断

考无穷大的运算，用“无穷大与无穷小互为倒数”。

分步解答
  1. C：f 是无穷大，它的倒数 1/f 是无穷小，极限 0 ✓。
  2. A 反例：f=1/(x-a)，g=-1/(x-a) 都是 ∞（这里 ∞ 指绝对值无限增大），相加为 0。A 错，D 也随之错（f+g=0 时 1/(f+g) 都无意义）。
  3. B 反例：f=g，f-g=0。B 错。
答案

C。

易错点

∞+∞ 不一定是 ∞（正负可以抵消），∞-∞ 是未定式。

通用方法

无穷大 ↔ 倒数是无穷小，这条永远成立；无穷大的加减要举反例检验。

考点四 · 第 14 题

极限 limx→-∞ x(√(x²+100) + x) = ______。

✍️ 先自己想：独立写出思路和答案，再展开下面的讲解。

第一眼判断

x→-∞ 时 √(x²+100) ≈ |x| = -x，括号内 ≈ -x + x，是 ∞-∞ 的形式，外面还乘 x → 有理化。

分步解答
  1. 分子分母同乘共轭式 √(x²+100) - x： x(√(x²+100)+x) = x·[(x²+100) - x²] / (√(x²+100) - x) = 100x / (√(x²+100) - x)。
  2. 现在是 ∞/∞，抓大头。注意 x<0：√(x²+100) ≈ |x| = -x，所以分母 ≈ -x - x = -2x。
  3. 原式 = lim 100x/(-2x) = -50。
答案

-50。

易错点

x→-∞ 时 √(x²) = |x| = -x，不是 x！写成 x 会得到分母 0 的错误。

通用方法

根号的 ∞-∞ → 乘共轭式有理化；x→-∞ 时把 √x² 换成 -x。

limx→2 [1/(x-2) - 4/(x²-4)] = ______。

✍️ 先自己想：独立写出思路和答案，再展开下面的讲解。

1/4。

通分后分子 x+2-4 = x-2，别算错符号。

通用方法

分式的 ∞-∞ → 通分化成一个分式，再约分。

极限 limx→0 (21/x + 1)/(21/x - 1) = ______。

✍️ 先自己想：独立写出思路和答案，再展开下面的讲解。

第一眼判断

含 21/x，x→0⁺ 时 1/x→+∞，x→0⁻ 时 1/x→-∞，两边完全不同 → 分左右。

  2. 左极限：x→0⁻，1/x→-∞，21/x→0。原式 → (0+1)/(0-1) = -1。

不存在。

易错点

没分左右，只算了一边。

通用方法

看到 a1/x、e1/x、arctan(1/x) 在 x→0，必须分左右。

考点四 · 第 17 题

极限 limx→+∞ [(2x²-1)/(x-1) - ax + b] = 0，则 a = ______，b = ______。

✍️ 先自己想：独立写出思路和答案，再展开下面的讲解。

第一眼判断

x→∞ 时分式 ≈ 2x，要减掉一次项才能为 0 → 先用多项式除法把分式拆开。

分步解答
  1. 多项式除法：2x²-1 = (x-1)(2x+2) + 1，所以 (2x²-1)/(x-1) = 2x + 2 + 1/(x-1)。
  2. 原式 = lim [(2-a)x + (2+b) + 1/(x-1)]。其中 1/(x-1)→0。
  3. 要极限为 0：一次项系数必须为 0，2-a=0 ⇒ a=2；常数项为 0，2+b=0 ⇒ b=-2。
答案

a = 2，b = -2。

易错点

题目是 “-ax + b”，b 前面是加号，所以 2+b=0。

通用方法

“lim[分式 - 一次式]=常数”型 → 把分式除成 多项式 + 余项，再让各次项系数匹配。

考点四 · 第 18 题

已知 limx→0 f(x) 存在，且 f(x) = (∛(1+x²) - 1)/tan x² - limx→0 f(x)，则 f(x) = ______。

✍️ 先自己想：独立写出思路和答案，再展开下面的讲解。

第一眼判断

lim f(x) 是一个常数，设成 A，两边取极限解方程。

分步解答
  1. 设 A = limx→0 f(x)（一个数）。则 f(x) = (∛(1+x²)-1)/tan x² - A。
  2. 两边同时取 x→0 的极限：A = lim (∛(1+x²)-1)/tan x² - A。
  3. 求这个极限（0/0 型，乘除因子用等价替换）：
  4. ∛(1+x²)-1 = (1+x²)1/3-1 ~ (1/3)x²（公式 (1+□)m-1 ~ m□，□=x²）
  5. tan x² ~ x²
  6. 所以极限 = (x²/3)/x² = 1/3。
  7. A = 1/3 - A ⇒ A = 1/6。
  8. 代回：f(x) = (∛(1+x²)-1)/tan x² - 1/6。
答案

f(x) = (∛(1+x²) - 1)/tan x² - 1/6。

易错点

题目问的是 f(x)（表达式），不是只填 1/6。

通用方法

“极限值出现在函数式里” → 设极限为 A，两边取极限解方程。

当 x→0 时，将 α = √(1-x) - 1，β = sec x - 1，γ = arcsin x - x 排序，使排在前面的是后面的低阶无穷小，则排序为______。

α, β, γ。

当 x→0 时，下列变量是无穷小量的为（ ）。A. 1/x²　B. 2ˣ　C. sin x　D. ln(x+e)

✍️ 先自己想：独立写出思路和答案，再展开下面的讲解。

第一眼判断

无穷小 = 极限为 0。逐个代入 x→0。

分步解答

A→∞；B→2⁰=1；C→sin0=0 ✓；D→ln e = 1。

答案

C。

易错点

无穷小是“极限为 0 的变量”，不是“很小的数”。

判断无穷小/无穷大，就是逐个求极限看是 0 还是 ∞。

极限 limn→∞ (n+1)/(3n²+1) · sin√(n²+1) = ______。

✍️ 先自己想：独立写出思路和答案，再展开下面的讲解。

第一眼判断

sin 部分不存在极限但有界；前面分式 → 0。“无穷小 × 有界 = 无穷小”。

分步解答
  1. (n+1)/(3n²+1)：抓大头，分子 1 次 < 分母 2 次，→ 0，是无穷小。

0。

通用方法

考点六 · 第 5 题

当 x→∞ 时，1/(ax²+bx+c) 和 1/(x+1) 是等价无穷小，则 a, b, c 为（ ）。
A. a=0, b=1, c=1　B. a=0, b=1, c 为任意常数　C. a=0, b, c 为任意常数　D. a, b, c 均为任意常数

✍️ 先自己想：独立写出思路和答案，再展开下面的讲解。

第一眼判断

等价 ⇔ 比值极限 = 1。

分步解答
  1. 比值 = (x+1)/(ax²+bx+c)，x→∞ 抓大头。
  2. 若 a≠0，分母 2 次 > 分子 1 次，极限 0，不行 ⇒ a=0。

考点七 · 第 7 题

极限 limx→∞ ((x+a)/(x-a))ˣ = 4，则 a = ______。

✍️ 先自己想：独立写出思路和答案，再展开下面的讲解。

第一眼判断

1∞ 型，先求出含 a 的结果再列方程。

分步解答
  1. u-1 = (x+a)/(x-a) - 1 = 2a/(x-a)。
  2. (u-1)v = 2ax/(x-a) → 2a，结果 e2a。
  3. e2a = 4 ⇒ 2a = ln4 = 2ln2 ⇒ a = ln 2。
答案

a = ln 2。

易错点

ln 4 = 2ln 2，别写成 a = ln4。

通用方法

反求参数 → 先求极限表达式，再解方程。

考点七 · 第 8 题

极限 limx→0 (cos x)1/ln(1+x²) = ______。

✍️ 先自己想：独立写出思路和答案，再展开下面的讲解。

第一眼判断

cos0=1，1/ln(1+x²)→∞，1∞ 型。

分步解答
  1. u-1 = cos x - 1 ~ -x²/2。
  2. v = 1/ln(1+x²)，ln(1+x²) ~ x²。
  3. (u-1)v → (-x²/2)/x² = -1/2，结果 e-1/2。
答案

e-1/2（即 1/√e）。

易错点

cos x - 1 是负的 x²/2。

通用方法

1∞ 公式 + 两个等价替换。

考点七 · 第 9 题

已知 f(x) = ˣ√(1-2x)（即 (1-2x)1/x），计算 limx→0⁺ f(x)。

✍️ 先自己想：独立写出思路和答案，再展开下面的讲解。

第一眼判断

x 次根号 = 1/x 次方，1∞ 型。

分步解答

(u-1)v = -2x·(1/x) = -2，结果 e-2。

答案

e-2。

易错点

根号上的小 x 是“开 x 次方”，要先改写成指数 1/x。

通用方法

根式先化成分数指数。

考点七 · 第 10 题

极限 limx→0 (1 + 3x)cot x = ______。

✍️ 先自己想：独立写出思路和答案，再展开下面的讲解。

第一眼判断

cot x = cos x/sin x → ∞，1∞ 型。

分步解答

(u-1)v = 3x·cos x/sin x，sin x ~ x，cos x→1，→ 3，结果 e³。

答案

e³。

易错点

cot x = 1/tan x，tan x ~ x，所以 cot x ≈ 1/x。

通用方法

三角函数指数先化成 1/tan x 再等价。

考点七 · 第 11 题

极限 limn→∞ [1/(1×2) + 1/(2×3) + … + 1/(n(n+1))]3n-2 = ______。

✍️ 先自己想：独立写出思路和答案，再展开下面的讲解。

第一眼判断

先把底数的和求出来（裂项相消），再看类型。

分步解答
  1. 裂项：1/(k(k+1)) = 1/k - 1/(k+1)。相加中间全部抵消，和 = 1 - 1/(n+1) = n/(n+1)。
  2. 底数 → 1，指数 → ∞，1∞ 型。
  3. u-1 = -1/(n+1)，(u-1)v = -(3n-2)/(n+1) → -3，结果 e-3。
答案

e-3。

易错点

裂项公式 1/(k(k+1)) = 1/k - 1/(k+1)，可以通分验证。

通用方法

求和型底数 → 先裂项求和，再用 1∞ 公式。

考点七 · 第 12 题

设函数 f(x) = limt→∞ (1 + 2x/t)ᵗ (x≠0)，则 f(ln 2) = ______。

✍️ 先自己想：独立写出思路和答案，再展开下面的讲解。

第一眼判断

极限变量是 t，x 当作常数；1∞ 型。

分步解答
  1. (u-1)v = (2x/t)·t = 2x，所以 f(x) = e2x。
  2. f(ln2) = e2ln2 = eln4 = 4。
答案

4。

易错点

谁趋于 ∞ 要看清（这里是 t），x 是常数。

通用方法

“极限定义的函数” → 先把 f(x) 求出来，再代值。
