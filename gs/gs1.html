做极限题的总流程

  1. 先代入：把 x 的趋向值直接代进去。能算出确定的数，那就是答案。
  2. 判断类型：代入后如果得到 00、∞/∞、0·∞、∞-∞、1^∞，这叫“未定式”，不能直接下结论，要变形。
  3. 按类型选方法：
    • 00：因式分解约分、有理化、等价替换、重要极限 sin□/□→1
    • ∞/∞（x→∞ 的分式）：抓大头，看最高次
    • ∞-∞：通分或有理化，化成分式
    • 0·∞：把一个因子挪到分母，变成 00 或 ∞/∞
    • 1^∞：重要极限 (1+□)(1/□)→e，或者用公式 lim u^v = elim (u-1)·v
  4. 分段函数、含 |x|、含 21/x、e1/x：必须分别求左右极限。

常用八个等价（x→0）：sinx、tanx、arcsinx、arctanx、eˣ-1、ln(1+x) 都 ~ x；1-cosx ~ x²2；(1+x)^m-1 ~ mx。补充：secx-1 ~ x²2，arcsinx-x ~ x³6，tanx-x ~ x³3。 等价替换只能换乘除因子，加减中慎用。

求极限先判断类型：不是未定式就直接代入；是未定式再按上面的方法处理。

考点二：函数性质

考点二考点讲解3:08
01

必背结论

  • 奇偶性（前提：定义域关于原点对称）：f(-x)=-f(x) 为奇（关于原点对称），f(-x)=f(x) 为偶（关于 y 轴对称）
  • 常见奇函数：x(2n+1), sinx, tanx, cotx, cscx, arcsinx, arctanx
  • 常见偶函数：x(2n), cosx, secx, |x|, 常数 C
  • 运算：奇±奇=奇，偶±偶=偶，奇±偶=非奇非偶；奇×÷奇=偶，偶×÷偶=偶，奇×÷偶=奇；复合函数内奇同外、内偶则偶
  • 周期：Asin/Acos(ωx+φ)+B 为 2π/|ω|；Atan/Acot(ωx+φ)+B 为 π/|ω|
  • 常考有界函数：sinx, cosx, arcsinx, arccosx, arctanx, arccotx
02

解题套路

奇偶性（前提：定义域关于原点对称）：f(-x)=-f(x) 为奇（关于原点对称），f(-x)=f(x) 为偶（关于 y 轴对称）

奇±偶=非奇非偶

考点四：函数极限

考点四考点讲解3:23
01

必背结论

题目

函数 f(x) 在点 x₀ 处有定义是极限 limx→x₀ f(x) 存在的______条件。

讲解视频1:41
查看逐步解答

第一眼判断

概念题，考“极限和函数值有没有关系”。

分步解答

  1. 记住结论：x→x₀ 的极限只看 x 靠近 x₀ 时 f 的走向，与 f(x₀) 有无定义、取何值无关。

答案

既不充分也不必要（无关条件）。

易错点

容易误以为“有定义”是必要条件。极限根本不看那一点本身。

通用方法

判断“A 是 B 的什么条件”，就分别问 A⇒B？B⇒A？各举一个反例。

查看逐步解答

既不充分也不必要（无关条件）。

4-17
题目

极限 limx→+∞ [(2x²-1)(x-1) - ax + b] = 0，则 a = ______，b = ______。

讲解视频1:59
查看逐步解答

第一眼判断

x→∞ 时分式 ≈ 2x，要减掉一次项才能为 0 → 先用多项式除法把分式拆开。

分步解答

  1. 多项式除法：2x²-1 = (x-1)(2x+2) + 1，所以 (2x²-1)(x-1) = 2x + 2 + 1(x-1)。
  2. 原式 = lim [(2-a)x + (2+b) + 1(x-1)]。其中 1(x-1)→0。
  3. 要极限为 0：一次项系数必须为 0，2-a=0 ⇒ a=2；常数项为 0，2+b=0 ⇒ b=-2。

答案

a = 2，b = -2。

易错点
