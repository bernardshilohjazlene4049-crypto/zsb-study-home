# 知识点目录与先修边表

`data/topics.json` 与 `data/dependencies.json` 用稳定的知识点编号、独立的先修边表，并把作答、错题、到期复习按知识点汇总。

组织方式参考了 [cn-math-taxonomy](https://github.com/xiaoyang111222/cn-math-taxonomy) 的结构思路（稳定编号、先修边、按知识点汇总），没有复制其文本或数据。该项目采用 [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/) 许可证。

高数先修边已按核对意见修订；英语各专题之间的先修关系目前仍是草稿，需要再核对。

存疑题 36-7、38-2、46-5 和第四、五章的补-5 不进入目录、先修、复习或错题汇总。
