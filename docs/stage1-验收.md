验收日期：2026-11-05。本轮只交付阶段 0 和阶段 1。阶段 2–5 只有说明状态的入口，没有辅导、识题、模考、沙箱、同步或 3D。

## 实际完成

- 七科目录来自 `data/subjects.json`。英语、高数、计算机基础、C 语言、网页设计为已上线，并链到真实页面；数据库和计算机网络为建设中，没有链接。数字电子技术默认关闭，不计入七科。
- 知识点页同一视图包含：已登记视频或「待添加」、可缩放 / 拖拽 / 折叠的 SVG 导图、笔记、示例题入口、掌握说明。掌握文案只表示已有练习证据，不写成完全掌握。
- 练习一次一题。已支持单选、判断、多选、填空；简答提交后是待评阅，不自动算对错。提交后先给解析，再选理解程度：会了、答对但不理解、不会想一步步学、看过仍不懂。
- 每次提交写入不可变 `attempt_id`。错题档案按学习者和题目合并，保留第一次的作答、判分、理解和分类。重练是新的 attempt。示例题单独分组，不进入真实正确率。
- IndexedDB `zsb-study` 保存作答、错题、笔记、进度、草稿、播放位置和收藏。设置页可导出 JSON、按 `schema_version` 导入、按 id 去重，并合并错题档案。清空有二次确认，只清本机库，不删仓库里的示例题。
- 演示题在 `data/questions/sample.json`，题干带「示例」，`provenance.kind` 为 `sample`。建议路径：高数「定义域」→ `gs/videos/1.mp4`（暂无定位）→ 示例单选 → 错题 → 重练 → 刷新 → 导出 / 清空 / 导入。C 语言「标识符示例」没有视频，显示「待添加」。
